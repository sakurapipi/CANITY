# CANITY

用纯 C 和 Win32 GDI 手写的 3D 恐怖生存小游戏。没有 OpenGL，没有 DirectX，
3D 投影、纹理采样、Z-Buffer、后处理全部由 CPU 在内存位图上逐像素完成。

**v1.0.1** · 纯 C · Win32 GDI · 软件光栅化 · 零外部素材 · 约 232KB

画面、文字、音效全部由代码程序化生成，仓库里没有任何图片、字体或音频文件。

---

## 玩法

在随机生成的迷宫里找保险丝，给配电箱通电，然后走进出口。
理智值随时间流失，归零就结束。

- **寻声怪** —— 听得见声音。走路是静音的，但冲刺、翻找箱子、手摇发电都会把它引过来。
- **追光怪** —— 看得见光。开着的手电筒会暴露你，扔在地上的荧光棒也会。
- **手电筒会耗电** —— 找电池，或者原地摇发电机。
- **每层随机词条和主题** —— 6 种词条、4 套场景主题、随机箱子内容。

```
探索迷宫 → 搜箱补给 → 找保险丝 → 配电箱通电 → 出口进下一层
```

## 操作

| 按键 | 作用 |
|---|---|
| `W A S D` | 移动 |
| `Shift` | 冲刺（会发出噪音） |
| `鼠标` | 转动视角 |
| `E`（长按） | 搜索箱子 / 启动配电箱 |
| `R`（长按） | 手摇发电 |
| `F` | 开关手电筒 |
| `G` / `B` | 投掷荧光棒 / 玻璃瓶 |
| `M` | 查看地图 |
| `ESC` | 暂停菜单 |

## 编译

需要 GCC (MinGW-w64 / MSYS2 UCRT64)。

```bash
gcc main.c -o canity.exe -O2 -Wall -lgdi32 -luser32 -lwinmm -mwindows
```

Windows 下也可以把上面这行存成 `build.bat` 双击运行。

- `-O2` 必须保留 —— 没有优化时渲染核心慢 5 倍以上
- `-lwinmm` 用于 `timeBeginPeriod(1)`，把 `Sleep` 精度从 ~15.6ms 提到 ~1ms
- 当前 `-Wall -Wextra` 零警告

## 开发背景

一次探索性的开发实验。借助 DeepSeek 的 API 开发，花费约 10 元人民币，
采用「AI 辅助 + 人工调试」的结对编程模式：AI 起草部分底层算法
（射线投射计算、波形合成），人类负责整体架构、多线程优化、内存排错，
以及反复的游戏手感调试。
