# CANITY

用纯 C 和 Win32 GDI 手写的 3D 恐怖生存小游戏。没有 OpenGL，没有 DirectX，
3D 投影、纹理采样、Z-Buffer、后处理全部由 CPU 在内存位图上逐像素完成。

**纯 C** · Win32 GDI · 软件光栅化 · 零外部素材 · 约 541KB

画面、文字、音效全部由代码程序化生成，仓库里没有任何图片、字体或音频文件。

---

## 玩法

在随机生成的迷宫里找保险丝，给配电箱通电，然后走进出口。
理智值随时间流失，归零就结束。

- **寻声怪** —— 听得见声音。走路是静音的，但冲刺、翻找箱子、手摇发电都会把它引过来。
- **追光怪** —— 看得见光。开着的手电筒会暴露你，扔在地上的荧光棒也会。
- **跳脸虫** —— 第 3 层起偶尔会从远处弹到你脸上。
  先按 `SPACE` 躲开，没躲开就得在倒计时里按下屏幕提示的键。
  躲错了会掉理智，还会有一阵子看不清、跑不动。
- **玻璃瓶能砸它们** —— 被砸中的怪会掉血、后退、僵在原地。砸掉 2~3 瓶就能赶跑一只。
  但瓶子碎裂的声音会暴露你的位置。
- **越深越危险** —— 怪会随层数越跑越快，被抓后的无敌时间也会越来越短。
  但你永远跑得比它们快：走路是静音的，代价只在「停下翻找」的那一刻。
- **第 24 层是终点** —— 给配电箱通电、走进那一层的出口，就算逃出生天。
- **手电筒会耗电** —— 找电池，或者原地摇发电机。
- **大厅永久升级** —— 用碎片买 4 列 20 节点技能树：更大电池、更快移速、更安静、
  理智更耐、手电更省电、安全屋回智更快，死后不丢。
- **每层随机词条和主题** —— 6 种词条、4 套场景主题、随机箱子内容。
  当前词条常驻显示在层数旁边（`LEVEL 7  HUNTED`），所以你知道这一层在惩罚你什么。
- **主动技能** —— 每局只能带一个，按 `Q` 释放，只受冷却限制。
  大厅的 `Skills` 页是一个列表：点某个技能就换上它（换技能会作废当前这局），
  对当前技能再点一次就是花残卷升级。
  三种：
  - **穿墙 PHASE**：2 秒内直接穿过墙，穿墙时墙体变透明，结束时若人在墙里会退回安全点；冷却 18 秒；
  - **透视 SIGHT**：5 秒内隔着墙标出怪物（红）、箱子（黄）、配电箱（青）、出口（绿）；冷却 20 秒；
  - **瞬移 BLINK**：沿视线瞬移最多 4 格（可越过墙，落点必须是空地）；冷却 12 秒。
  三种技能都能在大厅里花残卷升到 3 级：每级冷却 -15%、持续 +15%。
- **隐藏房间** —— 第 2 层起有可能出现一个小密室，门是一块金色暗门。
  要在本层找齐 **3 个密码碎片**（地上的青色光点）才能打开。
  密室里面有一个**高级箱**，开出 **残卷**、碎片和一件道具；
  高级箱只出这些，不会出保险丝，所以不会卡关。穿墙和瞬移也进不去。
- **残卷** —— 技能升级的唯一货币，只能从隐藏房间的高级箱里拿。
  每个技能 3 级，分别要 1 / 2 / 3 张残卷；碎片不能用来升技能。
- **上锁的箱子** —— 第 2 层起少量箱子带锁（金色锁扣），最多两个，不会层层都有。
  按 `E` 打开锁盘，四种锁随机出现：
  - **拨盘锁**：拨到正确数字会「咔哒」响一声并描绿圈，拨错是沉闷声；
  - **接线锁**：把左列端子按颜色连到右边同色的端子上；
  - **均衡器锁**：把三根推子推到各自的绿色标线；
  - **调波器锁**：示波器上一条暗的目标波形、一条亮的玩家波形，
    用三个旋钮（振幅 / 频率 / 相位）把亮线拧到与暗线重合。
  解完自动开箱，点 `BACK` 或按任意键退出。

```
探索迷宫 → 搜箱补给 → 找保险丝 → 配电箱通电 → 出口进下一层
```

## 操作

| 按键 | 作用 |
|---|---|
| `W A S D` | 移动 |
| `Shift` | 冲刺（会发出噪音） |
| `鼠标` | 转动视角 |
| `E`（长按） | 搜索箱子 / 启动配电箱 |
| `E`（对锁箱） | 打开密码锁盘 |
| `鼠标` | 锁盘：点按对应控件解谜（拨盘 / 端子 / 推子），点 `BACK` 退出 |
| `任意键` | 锁盘打开时按下即退出（方便听到怪就跑） |
| `R`（长按） | 手摇发电 |
| `F` | 开关手电筒 |
| `1 / 2 / 3` | 选择投掷物槽位（荧光棒 / 玻璃瓶 / 预留） |
| `鼠标左键`（按住） | 蓄力投掷当前选中物品（松开发射） |
| `鼠标右键` | 取消蓄力 |
| `SPACE` | 跳脸虫扑到脸上时推开它 |
| `Q` | 释放本局技能（目前是穿墙） |
| `M` | 开关右下角小地图（一边走一边看；不会被菜单、开锁或换层关掉） |
| `ESC` | 暂停菜单 |

以上全部按键都能在 Settings → Key Bindings 里改绑（含鼠标键），
跳脸虫的躲开键和 QTE 提示键也会跟随你的绑定。

## 编译

需要 GCC (MinGW-w64 / MSYS2 UCRT64)。

```bash
# Git Bash / MSYS2（通配符由 shell 展开）
gcc src/*.c -Iinclude -o canity.exe -O2 -Wall -Wextra -lgdi32 -luser32 -lwinmm -mwindows

# cmd.exe（不展开通配符，逐文件列出）
gcc src/main.c src/game.c src/entity.c src/render.c src/ui.c src/audio.c src/save.c -Iinclude -o canity.exe -O2 -Wall -Wextra -lgdi32 -luser32 -lwinmm -mwindows
```

项目结构：`src/` 放 `.c` 源文件，`include/` 放 `.h` 头文件，
公共常量与类型集中在 `include/common.h`。

- `-O2` 必须保留 —— 没有优化时渲染核心慢 5 倍以上
- `-lwinmm` 用于 `timeBeginPeriod(1)`，把 `Sleep` 精度从 ~15.6ms 提到 ~1ms
- `-Wall -Wextra` 目前还会报一些「未使用变量/函数」和 `snprintf` 可能截断的警告，
  这些是诊断信息，不影响生成 exe；看到警告不代表编译方式错了

## 开发背景

一次探索性的开发实验。借助 DeepSeek 的 API 开发，花费约 10 元人民币，
采用「AI 辅助 + 人工调试」的结对编程模式：AI 起草部分底层算法
（射线投射计算、波形合成），人类负责整体架构、多线程优化、内存排错，
以及反复的游戏手感调试。
