# v1.8.0 归档

这个 tag 只指向一份**归档说明**，不是 v1.8.0 的源码。

## 为什么

v1.8.0 的改动（3 列 15 节点技能树 + 存档路径三候选）
后来被并入 v2.0 的大重构，仓库主线从 v1.7.0 直接跳到了 v2.0，
中间那一版**没有单独提交**，源码已不可精确还原。

## 这一版有什么

- 挥刀：Q 键，独立冷却、不耗资源、伤害低
- 技能树：3 列 × 4 行 + 底部跨支 keystone，共 15 个节点
- 主线 10 层
- 存档路径三候选（exe 目录 → %APPDATA% → %TEMP%）
