# CANITY

一个使用纯 C 语言和 Win32 GDI (Windows API) 编写的 3D 恐怖生存小游戏。

## 项目简介

- **技术栈**：纯 C 语言、Win32 API、GDI、软件光栅化。
- **体积**：编译后约 231KB。
- **零外部资源**：不包含任何图片、字体或音频文件，画面、文字与音效全部由代码程序化生成。

## 开发背景

这个项目是一次探索性的开发实验。开发过程借助了 DeepSeek 的 API，花费约 10 元人民币，采用了“AI 辅助 + 人工调试”的结对编程模式。AI 负责了部分底层算法的起草（如射线投射计算、波形合成），而人类开发者负责整体架构设计、多线程优化、内存排错以及反复的游戏手感调试。

## 核心机制

- **3D 渲染**：基于 DDA 算法的射线投射（Raycasting），实现带纹理的墙壁与地板，以及距离阴影。
- **理智系统**：随时间流逝理智。理智过低时屏幕边缘会泛红，并伴有噪点特效。归零则游戏结束。
- **随机生成**：每局游戏会通过深度优先搜索（DFS）生成随机迷宫，并加入随机打通死胡同的逻辑。
- **声光双怪 AI**：
  - 寻声怪：在玩家冲刺、翻找或手摇发电机时，会被声音吸引并寻路追踪。
  - 追光怪：会被开启的手电筒或扔在地上的荧光棒吸引。
- **资源管理**：手电筒会耗电，需要寻找电池或手摇发电；寻找保险丝并启动配电箱，才能解锁出口。

## 操作说明

- `W A S D`：移动
- `Shift`：冲刺（会产生噪音吸引怪物）
- `鼠标`：转动视角
- `E`（长按）：搜索箱子 / 启动配电箱
- `R`（长按）：手摇发电
- `F`：开关手电筒
- `G` / `B`：投掷荧光棒 / 玻璃瓶（用于吸引怪物注意力）
- `M`：查看地图
- `ESC`：暂停菜单
