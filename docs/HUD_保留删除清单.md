# 局内左上角 HUD · 保留 / 删除 清单

> 2026-11-08。判定标准两条：
> **① 频次** —— 常驻 100% 的元素必须 100% 有用；
> **② 决策** —— 它出现时，玩家会因此做一件不同的事吗？
>
> 第二条不是我想的，是 `src/game.c:2059` 里早就写下的判据；
> 第一条来自 [HUD 设计原则](https://www.strayspark.studio/blog/game-ui-ux-design-principles)：
> 「如果一个血条 95% 的时间在屏幕上、只有 5% 的时间相关，就该改成条件显示。」

---

## 一、现在左上角到底有什么（按绘制顺序）

| # | 元素 | 何时可见 | 现在的位置 |
|---|---|---|---|
| 1 | `LEVEL n` + `CAMPAIGN/DAILY` | 100% | 第 1 行 |
| 2 | `GOLD n` | 100% | 第 1 行（接在 LEVEL 右） |
| 3 | `THREAT n.n` | 100% | 第 1 行（接在 GOLD 右） |
| 4 | 本层词条名（HUNTED / LEAKY…） | 100%（有词条时） | 第 1 行 |
| 5 | 本层事件名 | 100%（有事件时） | 第 1 行 |
| 6 | `SANITY: 100%` | 100% | 第 2 行 |
| 7 | `FUSES 0/2` / `POWER ON` | 100% | 第 3 行 |
| 8 | `CARRY n  TIER n` | 100% | 第 4 行 |
| 9 | `BOOST +n%` | 100% | 第 5 行 |
| 10 | 扳手状态（次数 / 冷却） | 100% | 第 6 行 |
| 11 | 主题房间名（FLESH CAVE） | 进房间时 | 右上 |
| 12 | 守门人堵门 / 清道夫翻箱 | 事件时 | 右中 |
| 13 | LIGHT / RUN 条 | 100% | 左下（不在左上） |
| 14 | CALIB 提示「HIDE TO USE」 | 100% | 左下 |

**第 1 行最多挤 5 项** —— 这是"乱"的主要来源。

## 二、逐条判定

| # | 元素 | 频次 | 改变决策？ | 判定 | 建议 |
|---|---|---|---|---|---|
| 1 | LEVEL | 100% | 弱（知道自己在第几层） | **保留但降级** | 缩成 `L3`，或并进地图页 |
| 2 | GOLD | 100% | **强**（决定能不能买/丢钱） | **保留** | 不动 |
| 3 | THREAT | 100% | **强，但要理解阈值** | **条件显示** | `> 0` 才出现；首次出现弹一句「威胁越高，怪越凶」 |
| 4 | 词条名 | 100% | **强**（它改规则） | **保留但换形式** | 图标 + 颜色（红=更凶），名字只在开场横幅 |
| 5 | 事件名 | 100% | 中 | **降级** | 开场横幅 5 秒，之后隐藏 |
| 6 | SANITY | 100% | **极强**（这是全局计时器） | **保留** | 不动，甚至可以更醒目 |
| 7 | FUSES | 100% | 强（但**拿到第一根前完全无关**） | **条件显示** | `fusesHeld > 0` 或 `breakerOpen` 才出现 |
| 8 | CARRY | 100% | 弱（元信息，开局永远是 0） | **删除** | 移到暂停页 / 商店页 |
| 9 | TIER | 100% | 中（跨档=怪变凶） | **删除** | 同上；跨档时用一次性提示 |
| 10 | BOOST | 100% | **无**（历史最高占比，纯元信息） | **删除** | 移到结算页 |
| 11 | 主题房间名 | 进房间时 | 无（氛围） | **缩** | 停留 2 秒淡出，或只在首次进入该房间时显示 |
| 12 | 守门人/清道夫状态 | 事件时 | **强** | **保留** | 已经是条件显示，正确 |
| 13 | LIGHT / RUN 条 | 100% | **强** | **保留** | 不动（在底部，不在左上） |
| 14 | CALIB 提示 | 100% | 无（教程项） | **只在教程显示** | 正式局隐藏 |

## 三、删完之后剩下什么

### Minimal（新手默认）

```
SANITY 100%          ← 计时器
GOLD 0               ← 资源
THREAT 0.0           ← 只在 >0 时出现
（左下）LIGHT ▓▓▓░   ← 已有
（左下）RUN   ▓▓░░   ← 已有
```

**屏幕上永久只有 3 个数字 + 2 个条。** 这是新手第一局该看到的全部。

### Normal（默认）

```
SANITY 100%   GOLD 0   THREAT 0.0
FUSES 1/2            ← 拿到第一根后出现
[HUNTED]             ← 词条做成图标，不写全名
LIGHT / RUN 条
```

### Full

```
+ CARRY / TIER / BOOST
+ 词条全名 + 事件名
+ 主题房间名常驻
+ 扳手次数
```

## 四、三条配套改动（不然删了会丢信息）

1. **按 Tab 展开完整 HUD** —— 常驻只留 4 项，按住 Tab 临时看全部。
   信息没删，只是默认不糊在脸上。这是调研里"on-demand"那一类。
2. **威胁值首次 > 0 时弹一句解释** —— 现在新手看到 `THREAT 0.0` 完全不知道是什么。
3. **跨强度档时给一次性提示** —— TIER 从左上角删掉之后，
   跨档（怪听觉 +5%）这件事必须有别的通道告诉玩家。

---

## 五、为什么这样删（一句话）

> 「每个加进 HUD 的元素都在偷走玩家对世界的注意力。」
>
> 现在的左上角有 **10 项常驻信息**，其中 **4 项（CARRY/TIER/BOOST/事件名）
> 在开局时全是 0 或纯氛围**。删掉它们，新手的认知负担直接减半。

## 附：删除清单（可直接执行）

| 动作 | 元素 | 落到哪 |
|---|---|---|
| **删** | `BOOST +n%` | 结算页 |
| **删** | `CARRY n` | 暂停 / 商店页 |
| **删** | `TIER n` | 暂停页 + 跨档一次性提示 |
| **条件** | `THREAT` | `> 0` 才显示 |
| **条件** | `FUSES` | 拿到第一根后显示 |
| **条件** | `CALIB` 提示 | 仅教程 |
| **缩** | 主题房间名 | 2 秒淡出 |
| **缩** | 词条名 | 图标 + 颜色 |
| **缩** | `LEVEL 3` | `L3` |
| **保** | SANITY / GOLD / 词条（图标） / 守门人状态 / LIGHT / RUN | 不动 |
