# CANITY v2.4.8 正式版

本版整合此前2.4.8 RC/RC2源码与试玩修补，保持36×36地图、12个容器槽及v45存档结构。

## 内容与交互

- 七种主题房间重制、整层风格统一、宽敞多出口布局与独立主题图鉴。
- 中央装置负责启动；房间状态、操作条件和结果整合到左上信息框。
- 债务密库3—10箱、独立有界金币奖池、共享整数分配、少量道具与低概率保险丝；普通箱和保险丝进度保留独立规则。
- 通关选项1/空格继续，2撤离并二次确认；支持鼠标、键盘和手机触控。
- 小游戏打开后等待Q/W/E/R启动，并留出倒数；彩色轨道、精准命中、连击、提高回电与专用音乐播放。
- 地图玩家标记恢复连续位置移动；设施符号提亮、去重并按格子缩放。
- 隐藏点内禁用手摇发电；20点低电量双鸣。

## 表现与怪物

- 稳定原版视角与实验性上下视角保持独立，默认关闭实验功能。
- 七类隐藏点、容器与配电箱、主题装置准备和运行姿态。
- 大型前景道具遮挡同一路径上实际可见怪物时半透明；不穿透墙体显示怪物。
- 地面安全色块改为轮廓角标，不再用绿色实心光池。
- 听声鬼首层放置距离调整；威胁分别作用于听觉、感知范围、移动或锁定时间，并保持硬上限。
- 清道夫出现提示“Something is coming.”，守门人完成锁定提示“You have been targeted.”；不恢复常规怪物遭遇播报。
- 主页配乐移除金属噪音冲击，隔离上一局低理智音频效果；局内配乐保持原风格。

## 下载与兼容

Windows Lite包解压后双击canity.exe，保留music目录及许可证。网页和手机版共享同一WebAssembly构建，可从项目GitHub Pages访问。
存档结构仍为v45；升级前保留个人存档备份。新版主题事件和专属箱语义不应通过旧程序继续运行。
