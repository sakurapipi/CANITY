# CANITY v2.5.0 RC1

## 失序协议

- 维修员程默在调度站部署过载防线，切断伪造救援广播。
- 档案员林岑让记忆替身穿过证词接收器，取回被封存的录音。
- 隔离警卫沈砚用战术防御接下泄压冲击，打开最后的撤离通道。
- 三章以探索、现场记录和技能解谜为主，关卡内不会刷新怪物。每章都有独立的墙地材质、装置模型和地图图标。

## 玩法和界面

- 角色档案展示能力、消耗和基础属性。局内显示技能状态，局内商店新增角色能力调校。
- 局外技能通用于所有角色。重做旧节点并修复掩体标记、静默起步、无形、应急补给等效果。
- 主菜单右侧插画保持固定，经典模式的宝箱怪伪装随当地材质变化。断路脉冲弹新增落地电弧。
- 经典地图仍为 36×36，容器槽仍为 12。

## 存档与下载

- RC1 写入 v46 存档。切换版本前请备份存档。新开剧情进入三章流程，已有旧剧情进度可继续原路线。
- Windows ZIP 完整解压后运行 `canity.exe`，保留旁边的 `music/`。网页 ZIP 可通过 HTTP 服务运行，单文件 HTML 可直接打开。
- Windows 和网页下载均由同一发布标签构建。`build-manifest.json` 列出提交和附件 SHA-256。
