> 用户原话：「以后进这个游戏的代码，优先级都必须过一次那个防耦合和多模块化。」

> `python -X utf8 tools/coupling_gate.py` 返回 **PASS**。

## 一、怎么用

```sh
python -X utf8 tools/coupling_gate.py            # 详细报告
python -X utf8 tools/coupling_gate.py --quiet    # 只在失败时输出
```

退出码 `0` = 放行，`1` = 拦截。**FAIL 时不允许提交/打包/发布。**

## 二、五条硬规则

| # | 规则 | 阈值 | 说明 |
|---|---|---|---|
| 1 | **域预算**：每个域的「最大单文件 + 头 + 功能卡 + 域测试」 | ≤ **2500** 行 | 改一个域需要读的量；超过就说明这个域该拆了 |
| 2 | **单文件上限** | ≤ **2600** 行 | 任何 `.c` 超过就拆文件 |
| 3 | **函数上限** | ≤ **300** 行 | 超过必须拆成阶段函数 |
| 4 | **函数软上限** | >200 行的函数 ≤ **10** 个 | 不强制为 0，但不许再涨 |
| 5 | **登记完整** | 100% | `src/` 下每个 `.c` 必须进 `build_sources.py`；新 `src/domain/<x>/` 必须进 `module_cost.py` 的 `DOMAINS` |

## 三、什么算「耦合」——拆的判据

不是按行数乱切，而是按**这三条**判断一块代码该不该独立：

```
① 它有自己的状态吗？
   有 → 状态跟着它一起搬走（S3：符号归属），不许留在原文件里被别处 extern

② 它的依赖干净吗？
   只依赖公共 API（present_api / player_api / world_api）与基础头 → 可以搬
   依赖另一个模块的 static 变量 → 先抽接口，再搬

③ 它对外只暴露几个入口？
   1~2 个入口 → 健康
   一堆入口互相调用 → 说明切错了，应该按"职责"切而不是按"文件"切
```

**已验证的第一块**：`src/domain/render/render_map.c`
```
RenderMap + DrawMapLegend（313 行）整体搬走
依赖只有 PutPixel/BlendRectWin/DrawTextWin/MAP_* 与 explored/mapFullScreen
→ 一次编译通过
```

## 五、豁免

只允许两类豁免，且必须写进 `tools/coupling_gate.py` 的豁免表并注明理由：

```
EXEMPT_FILES  生成数据，例如 src/cjk_glyphs.c（11358 行中文点阵表）
WEB_ONLY      只被网页构建使用的实现（audio_web.c / plat_web.c / *_web.c）
```

**不许**因为"拆不开"就加豁免。拆不开 = 接口没设计好。

## 六、新功能怎么写（流程）

```
1. 先定域：属于哪个既有 DOMAINS 条目？不属于 → 新建 src/domain/<x>/ 并注册
2. 写接口：头文件只放该域对外契约（S5：不许把 game.h 私有头带出去）
3. 写实现：状态 static 在本文件；跨域只走 public API
4. 过闸门：coupling_gate PASS + build_validate 全绿
5. 记账：域超预算就当场拆，不许"先合进去以后再说"
```
