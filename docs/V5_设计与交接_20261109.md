# CANITY V5 改造交接

本轮以《给GPT的提示词_最终版_2026-11-09.md》为需求；用户后续明确音乐也由实现方原创生成，验收与推送由用户负责，全部内容完成后统一交付。没有执行分阶段提交、验收或推送。角色和怪物模型沿用原资产。

## 运行与资源

- Windows 包提供 `canity.exe`、`开始游戏.bat`、`music/` 六首 WAV 和谱面、独立 `saves/`。ZIP 必须完整解压，不能只取 EXE。
- `music/menu.wav`、`explore.wav`、`chase.wav`、`safe.wav`、`victory.wav`、`defeat.wav` 均由 `tools/compose_score.py` 合成，没有下载歌曲或使用采样。
- 44100 Hz / PCM16 / 双声道；72–80 秒的循环，具体长度、电平和 SHA-256 由 `music/score-manifest.json` 记录。这些是素材生成数据，不是试听通过证明。
- `python tools/compose_score.py` 可离线重建六首曲目、JSON 谱面和 `include/score_charts.h`，依赖 NumPy。所有固定随机种子随源码提供。
- 金属刮擦、低频撞击和不协和金属击打，分别安排在第 6/12/18 小节，前一小节压低至安静。没有整曲淡出尾巴；振荡器整周期量化，事件和反射环形写入。
- 默认使用文件音乐。单曲缺失时该场景回落到内置音乐；保留 `CANITY_MUSIC=builtin/files`。文件加载在启动完成，音频线程只读不可变 PCM；退出时避免在工作线程可能晚退的情况下释放样本。
- Windows WAV 与内置音乐进入同一后处理总线；低理智降低低通截止频率、叠加轻微噪声和加速心跳。WAV 有微量失谐。MP3 兼容路径仍由系统 MCI 播放，不能提供 PCM 总线的全部处理；本轮交付全部使用 WAV。
- 音效仍启动时合成，追加 11 类素材，不依赖外部音效。混音取声部使用非阻塞锁尝试；重要音效压低音乐。主音量控制音乐和音效，暂停淡出。
- 网页端接入同名 WAV、浏览器解码缓存、低通/微失谐/噪声/心跳与逐曲合成回落；网页产物旁必须保留 `music/`，通过 HTTP 服务访问。

## 表现与界面

理智阈值集中在 `perception.h`：80% / 50% / 20%。上限 `PERCEPTION_GRAIN_MAX=7`；3.7 秒片段内由确定性散列选择不规则低幅灯管脉冲，最大衰减 5%，高于 80% 无颗粒、闪烁、畸变。感知数据平滑插值，低理智射线角轻微扰动，不再移动渲染相机穿墙。蓝色暗角保留中心可读性，崩塌渐晕接近全黑后重掷。污染仅用于标题，金额文字统一暖金。

主菜单采用全屏透视门框和单轴列表，去掉最高层。常用入口收拢，成就、帮助、设置及特殊模式留在“档案与模式”，未删除旧模式。鼠标、回车、空格购买入口保留。

帮助分基础操作、核心循环、全部局外技能、怪物、经济与局内技能；直接读 50 个玩家节点、28 个局内节点和原有 25 张局内卡的实际定义。技能分类可输入中文或英文名称定位，支持退格。

## 两种训练

主菜单自由训练营保留原场地与无限补给。正式对局按 B 先保存，再进入独立线性引导；完成后恢复原对局，不用训练物资覆盖正式存档，也不额外提取银行金币。

新引导只推进真实完成的六步：移动至少一格 → 手电关闭再打开 → 首箱取保险丝 → 实际投掷 → 进入藏身点 → 抵达走廊出口。仅提供一枚光球、两枚石头；不无限补充。引导的站点不会再跳过步骤。

## 校准与服务

- 空格开始，左侧 QWER 四轨下落；两次空格间隔不超过 350 ms 则取消。
- 当前曲目的中间 40 秒；10 ms 能量窗、正向能量差、78% 分位门槛，240 ms 最小起音间隔；SHA-256 和起音序号决定轨道。JSON 有 `start_sample`、`duration_ms`、`pcm_sha256`、音符时间/轨道/难度。
- 1–3 层取一档起音，4–7 层取两档，8 层起全谱；判定窗从 ±180 ms 收紧至 ±85 ms。
- 错轨、空击、漏音均计错并断连；累计五次立即失败。失败/取消不发奖，冷却 30 秒。
- 连击第二下积累 2 点、第三下积累 3 点，按三连周期累计，最多 10；完整完成后才结算。结算不超过本轮实际被动理智流失量；音游期间停用藏身的被动回血。无金币、电量奖励。
- 当前文件音乐或谱面未就绪时拒绝开始，避免对着不匹配的回落音乐假装有可用谱面。
- 修整报价 `ceil(12 + 96 × (1 - 当前理智/理智上限)^2)`，最多恢复 40×改造倍率，冷却 90 秒。例：30% 理智约 60 金币，50% 理智 36 金币；预览与扣款共用函数。
- F5 刷新补给，冷却 60 秒，显示剩余时间；冷却持久化，并在商店界面计时。

## 怪物出场与数值

听声鬼听觉倍率 100% / 75% / 50%。第二只保留减速能力；第三只速度倍率1.26。基准速度 `1.30 + min(.35, .035×(层数-1)) + min(.12,.006×威胁)`，第一/二只封顶1.85，第三只封顶2.25，低于未加成步行2.5，且冲刺仍能拉开距离。怪物词条参与计算后仍封顶。

首只入场 `max(22,55-3×(层数-1))` 秒；后续第2/3只在该基数的2/3倍时刻申请生成，并保留难度和有限威胁提前量。
