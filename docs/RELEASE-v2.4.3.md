# CANITY 2.4.3 正式版 — 水平视角更新

应用户要求，取消上下转视角，降低操作时的眩晕感。

- Windows 鼠标与网页鼠标忽略垂直视角输入，左右转向保持不变。
- 手机触摸只控制左右转向；上下滑动不再使镜头抬头或低头。
- 每次渲染固定水平视角，避免暂停、继续游戏等路径残留倾斜。
- 存档格式仍为 v45，兼容 2.4.2 进度；其余玩法不变。
