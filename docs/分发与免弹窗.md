# 分发与「免弹窗」

> 这个文档回答一个问题：**为什么别人电脑上双击 canity.exe 会弹「Windows 已保护你的电脑」，
> 以及怎样彻底消掉它。**

---

## 1. 弹窗到底是什么

不是游戏报错，是 Windows 在执行前拦的一道。触发条件只有一个：

**这个 exe 带 MOTW（Mark of the Web，"来自 Internet"标记）。**

从浏览器、微信、QQ、网盘客户端下载的 exe，文件上会多出一个备用数据流：

```
canity.exe:Zone.Identifier
    [ZoneTransfer]
    ZoneId=3          ; 3 = Internet
```

带这个标记的文件第一次运行时，系统按当前策略弹两种框之一：

| 框 | 由谁弹 | 表现 |
|---|---|---|
| 打开文件 - 安全警告（"无法验证发布者"） | 附件管理器 | 灰色小窗，有「运行(R)」按钮 |
| Windows 已保护你的电脑 | SmartScreen | 蓝色全屏页，要「更多信息 → 仍要运行」 |

**同一个文件，只要 MOTW 去掉了，两个框都不会再出现**（除非文件被安全软件判毒）。

自己编译出来的 exe 没有 MOTW —— 所以本地开发永远看不到这个框，
只有发到别人电脑上才会遇到。这就是它"发线上才发现"的原因。

---

## 2. 为什么"代码里改不掉"

进程启动之前，系统就已经做完判断了。游戏代码根本没机会运行，
自然也没机会"把自己解锁"。

因此这一类问题只能在**分发方式**上解决。

---

## 3. 三条路，按彻底程度排序

### ① 代码签名（唯一真正的"彻底"）

买一张 Authenticode 代码签名证书（OV 约 ¥1500/年，EV 约 ¥4000/年），
用 `signtool` 签 exe：

```
signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 ^
              /a canity.exe
```

- OV 证书：签名后仍然要**攒下载量**，SmartScreen 前一段时间还会警告，
  但"未知发布者"会变成你的公司名；量上来之后完全消失。
- EV 证书：**立刻**获得 SmartScreen 信誉，第一天就不弹。

> 自签名证书（`New-SelfSignedCertificate`）**没用**：它不是受信任的根，
> 弹窗从"未知发布者"变成"签名无效"，甚至更吓人。

### ② 用安装包分发（实际效果等同于没弹窗）

玩家下载的是 `CANITY_Setup.exe`（安装器本身会被拦一次），
安装器把游戏解压/复制到 `C:\Program Files\Canity\` ——
**装出来的 canity.exe 不带 MOTW**，之后每次双击都不会弹。

安装器只被拦一次，而且大多数玩家已经习惯"装软件要点一下仍要运行"。
这是没有证书时最靠谱的做法。

推荐 Inno Setup（免费、脚本化、单文件输出）：

```ini
; canity.iss —— 装 Inno Setup 后运行 ISCC.exe canity.iss
[Setup]
AppName=Canity
AppVersion=1.8.0
DefaultDirName={autopf}\Canity
DefaultGroupName=Canity
OutputBaseFilename=CANITY_Setup_v1.8.0
Compression=lzma2
SolidCompression=yes

[Files]
Source: "dist\CANITY_v1.8.0_win64\canity.exe"; DestDir: "{app}"
Source: "dist\CANITY_v1.8.0_win64\第一次运行请看.txt"; DestDir: "{app}"; Flags: isreadme

[Icons]
Name: "{group}\Canity"; Filename: "{app}\canity.exe"
Name: "{autodesktop}\Canity"; Filename: "{app}\canity.exe"
```

### ③ 便携 zip + 解除锁定脚本（我们现在的做法）

`python tools/package_release.py` 产出的 zip 里带一个 `解除锁定.bat`，
玩家解压后先双击它：

```
powershell -NoProfile -Command "Get-ChildItem -LiteralPath '<目录>' -Filter *.exe | Unblock-File"
```

`Unblock-File` 删掉的就是 `Zone.Identifier` 那个数据流。跑完再双击游戏就不弹了。

缺点：**玩家得先看懂说明**。所以 zip 里那份 `第一次运行请看.txt` 第一段就写这件事，
而且给了"右键 → 属性 → 解除锁定"这个不用跑脚本的备选路径。

> 注意：zip 本身也可能带 MOTW，解压时用资源管理器会把标记**传给里面的文件**；
> 用 7-Zip / WinRAR 解压一般不传。这就是为什么要保留 `解除锁定.bat` ——
> 不管玩家怎么解压，跑一次都能修正。

## 4. 已经在代码/资源层面做掉的（exe 不再像"三无程序"）

`res/canity.rc` 用 windres 编进去三样东西：

| 资源 | 作用 |
|---|---|
| `1 ICON canity.ico` | 资源管理器/任务栏显示真图标（16→256 多尺寸） |
| `VERSIONINFO` | 属性页有产品名、版本、版权；`OriginalFilename` 便于系统识别 |
| `1 24 canity.manifest` | 进程清单（见下） |

清单里声明了三件事：

- **`asInvoker`** —— 明确"不需要管理员权限"。没有这一条时，系统对
  "可能需要提权"的未知程序会更谨慎。
- **`supportedOS` Win10/11** —— 防止系统给 exe 套**兼容性垫片**。
  垫片会带来文件和注册表重定向（写入被悄悄导到 VirtualStore），
  这正是"存档写不进去"的经典成因之一。
- **`dpiAware=true` + `longPathAware`** —— 和代码里 `SetProcessDPIAware()`
  保持一致；装到深目录时路径超 260 字符也不会失败。

> **故意没用 PerMonitorV2**：那会让 `GetSystemMetrics` 返回物理像素，
> 而 `winW/winH` 直接决定全屏逻辑和鼠标坐标换算 —— 换感知级别等于换一套坐标系，
> 没实测过不能动。

---

## 5. 玩家还是报错时，让他提供什么

1. 弹窗那一页的**截图**（要能看清标题：是"安全警告"还是"已保护你的电脑"）
2. `canity.exe` 所在**完整路径**
3. 把下面这条命令的输出发过来（PowerShell）：

```powershell
Get-Item .\canity.exe -Stream * | Select-Object Stream, Length
Get-AuthenticodeSignature .\canity.exe | Select-Object Status, StatusMessage
```

- 有 `Zone.Identifier` 流 → 就是本文说的 MOTW，按第 3 节任一方案处理
- 没有流但还弹 → 是安全软件（火绒/360/管家）在拦，加信任区
- `Status` 不是 `Valid` → 没签名或签名过期

---

## 6. 构建命令（含资源）

```bash
windres res/canity.rc -O coff -o res/canity_res.o
gcc src/*.c res/canity_res.o -Iinclude -o canity.exe -O2 -Wall -Wextra \
    -lgdi32 -luser32 -lwinmm -mwindows
```

`tools/package_release.py` 会把上面两步 + 附带文件 + 打 zip 一次做完，
并且自检"清单和版本信息是否真的嵌进去了"。
