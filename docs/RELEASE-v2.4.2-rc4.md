# CANITY 2.4.2 RC4

## 本轮修复

- 网页Tab按住小地图、松开关闭；共享KeyUp处理不再依赖Windows消息。失焦与全屏切换后释放输入。
- 小地图在精神污染及遮蔽层之后合成；暂停及暂停设置页不绘制眼睛，避免溢出。
- Web热循环恢复O3优化；自动画质在启动时选择较低的浏览器像素预算，不在追逐中反复改变UI大小。
- 全屏／退出按钮常驻上层，显示当前状态；支持Esc退出，拒绝请求时回退窗口模式。
- 手机挥击映射到真实扳手绑定：按住预备蓄力，松开挥击，不依赖旧V键。
- 局内／局外技能树共用触摸拖动，松手再判定点击，拖动不误购买；金币左侧提供加减缩放按钮。
- 提高蜘蛛的合格楼层出场率：55%起，随层数和压力增长，上限85%，保留首层限制与驱散冷却。
- Windows 默认 **Lite 构建**：EXE 约 2 MB，音乐从外部 `music/` 目录读取，需与 EXE 一起保留；可选 `build_validate.py --embed-music` 构建嵌入 MP3 的 Full 单文件版。存档仍在用户目录，保留外部 `CANITY_DATA_DIR` 设置。

## 验证范围

完整C99编译、离线契约、全部15个隔离运行域与内容／分区／布局／热键等检查需全部通过。新增地图松键、双向拖动、拖动不误购、缩放、蜘蛛门槛和暂停眼睛绘制反例。

Edge实际浏览器自动回归17项已通过，包括Tab松开、五轮全屏往返、移动触摸扳手蓄力和挥击、局外树缩放和平移，页面错误为零。同机960×540示例场景记录旧版59.0 FPS、新版59.7 FPS；这是当前电脑与场景的测量，不保证所有手机或低端机都达到60 FPS。触屏用浏览器模拟，不冒称实体手机全机型验收。

版本为2.4.2-RC4，存档仍v44，地图36×36，容器槽12。最终发布提交及远端CI以GitHub实际运行记录和发布清单为准。
