# CANITY v2.5.0 RC2

- 「失序协议」在菜单上标为剧情序章。每章先取得一份关键证据，再进行角色能力试运行，最后读取终端开启撤离。
- 维修员用真实的阻滞区减速移动滑台，档案员用替身引开移动拾音器，警卫在泄压警报响起后举盾承受冲击。失败后可重新启动装置。剧情依然没有随机怪物。
- 当前目标跟随证据、试运行、终端及撤离更新。设置中的「目标引导」可收起提示。
- 剧情净收益扣除初始补给额度后最多入账 220 金。首次完成序章额外奖励 500 金，结算显示实际入账。无尽模式解锁仍走经典探索或原战役的通关进度。
- 序章关闭角色专属节点购买。继续 RC1 的序章存档时，原有专属节点在该章结束时按原价退还，并移除相应威胁。其他模式保持原有构筑入口。
- 存档仍用 v46，旧存档的已购局外节点按原 ID 保留。可在技能详情查看重制说明。保存中途退出时，本章已经读过的证据及已经完成的装置会保留，正在进行的装置试运行可在读档后重新启动。

## RC2 更新

- B-17 撤离事故串联三个重新布局的剧情楼层。新地图保留维修员滑台、档案员拾音器和警卫泄压闸玩法。
- 投掷物的怪物命中、落地、撞墙与到期共用效果结算。胶瓶命中也会生成胶水。玩偶诱饵持续 15 秒，声响可以沿连通走廊传到半张地图宽。
- 过载灯塔在左右两塔充电后揭示全图 35 秒，前 15 秒小地图免耗电。声源诱导井用 X 展开半透明引导。按 J 打开背包，可调整投掷物排序，K 丢弃金币。
- 键位设置显示实际绑定，补齐中文标签。FPS 面板避开主要 HUD，风险银行说明契约设定最低威胁档。节奏校准保留逐步加速，每局按键奖励最多恢复 55% 理智上限、80% 电量上限。
- 飞行、命中、诱饵和荧光棒治疗分为独立模块，帧率显示独立于玩法 HUD。Windows 下载包剥离符号，保留自动化日志供排查。
