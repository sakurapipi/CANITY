# CANITY v2.4.9-RC3

基于 v2.4.9-RC2 的预发布版。

- **生存指南与训练**：新增分页指南、实时键位、怪物和工具索引。从「新手教程」进入引导层，沿菱形路标完成操作后进入训练场。B 可直接进入训练场。训练场分为锁具、靶场、藏身休整和配电撤离四区。
- **每日挑战**：仅当天的每日地图可推进任务，经典、战役和无尽对局独立结算。
- **投掷物**：移除连投回响，保留回声弹的扫描与标记。投石使用独立弹道，砸锁有专属音效和震动。胶水增加落地波纹，烟雾改为多层烟团，进入烟雾时照明接近关灯。傀儡被击毁会提示。
- **交互与平衡**：通关面板独立显示。局内技能单击查看、双击购买，节律小游戏结束后有 0.3 秒输入保护。清道夫速度介于基础步行和冲刺之间。四档失败返还为 35%、28%、21%、15%，金币压力权重为 RC2 的 1.5 倍。
- **音效与成就**：听声鬼 2、3 号分别使用独立脚步声，偷钱怪增加轻微金属声。成就页汉化，按未完成、已完成排序，调整一次性奖励并归档旧版重置成就。存档主体仍为 v45。

Windows 包解压后运行 `canity.exe`，并保留同目录的 `music/`。网页可使用 ZIP 或单文件 HTML。构建清单记录了源码提交和附件 SHA-256。
