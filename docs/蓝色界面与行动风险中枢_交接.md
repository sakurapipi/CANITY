# 蓝色界面与行动风险中枢：本轮源码交接

## 范围

源码修改阶段未构建。随后按用户要求补做 Windows 构建与桌面运行包，修复输入模块缺少 ui_menu.h 的编译问题。没有启动游戏、运行验收测试、提交或推送。新版文件夹、ZIP 和桌面“CANITY 最新运行版”快捷方式已生成。

## 界面与语言

- 主菜单、局外技能、成就、图鉴、银行和安全屋统一冰蓝强调色、深蓝底、蓝灰边框；通用九宫格不再画旧琥珀皮肤。
- 显式 Tr(英文,中文) 优先使用本地准确中文，不再被全局同名词覆盖。技能名称、效果描述按稳定 ID 提供双语版本；小节点按完整 UTF-8 字符截断，不再翻译截断后的英文缩写。
- 修复 GOLD 动态前缀长度和翻译临时缓冲复用；中文字库按当前 C/头文件/生成词条重新烘焙。限制文字缩放在现有四档图集范围，保持测量与绘制一致。字形生成属于资产写入，不是真机验收。
- 遭遇字幕的生产点与播报接口已移除；图鉴照常静默记录。怪物音效、行为、伤害、追逐、掉钱等游戏事件保留，不靠清空游戏状态消除字幕。

## 安全屋

可见页签变为四个：补给商店、局内技能、休整服务、属性强化。退役改装页的逻辑和入口移除，原 ID 1 留空，其他 ID 不重排。键盘切页、鼠标页签均通过同一映射。

补给使用四张立式商品卡，窄窗口两列两行。现有道具图标用于展示，电池和医疗包使用简单功能图标。折扣有独立条带、原价划线、实付价格和补货状态。显示和付款都使用实际商品 ID，修复相位信标落到普通商品行后错误套用行号价格的问题。

休整是四张服务卡，显示资源条、缺口、实际恢复量、价格、每层限制和可用状态；满资源不扣钱、不浪费本层次数。休息恢复按局内恢复属性生效。

强化分卡显示等级点、精确每级效果和价格，保留六项原属性与原等级存储。契约提示只显示本局计划，不再挤在一行里偷偷切换协议。

卡片绘制与鼠标命中共用矩形，鼠标点击不会再沿旧横排列表误买；键盘仍沿稳定行号选择。

## 技能树

局外：45 个定义、44 个玩家节点，包含起点；内部 ID 40 继续隔离。增加反击者四项机制：镇定窗口、利落脱身、看准破绽、佯攻诱敌。所有新技能有实际触发入口，不增加角色模型。

局内：24 个节点，新增软底鞋、工具散热、野外休整、应急照明，以有上限的属性与条件效果为主；只扣局内金币。原 ID、已购位及顶点二选一保留。

局外支持回车、空格、左键点击节点购买，并提供独立购买/装备按钮。原生拖动达到阈值后仅平移，不购买；修复鼠标消息已是客户区坐标却再次 ScreenToClient 的错位，以及未开始拖动却被误认作单击的问题。Web 使用同一个购买入口。

## 银行与压力

银行改成行动风险中枢：携带比例滑条和风险契约滑条分别调整本金与风险方案，支持拖动、键盘选择与调整、保存和返回。预测不改写正在进行的对局状态。

显示下一局携带金额、基础金币压力档、感知倍率、契约撤离倍率和失败返还比例。明示金币不直接提高怪物速度，战役/每日规则可另外修正。选择的契约在新局初始化时实际生效，并在本局锁定，不再由强化页循环改变。

## 图鉴与闪屏

听声鬼档案展示三只现有形态的肖像，共享听声鬼的既有解锁与研究记录，不复制三份存档进度。

移除低电量的周期手电闪光、敌人接近时的灯光闪烁、恢复时全屏白闪与换层白屏。渲染反馈不再把相机位置平移进墙体；保留实际受伤时的边缘提示和资源条。是否完全解决用户看到的走路闪烁，需用户实际验收，不能以源码修改代替确认。

## 存档
