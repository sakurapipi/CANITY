# 常量与空操作接口分类

这是本轮源码整理时写入的分类清单，不是测试运行结果。状态字段查询不属于常量桩，例如 CollectorActive 读取 collector.active，DailyCurrent 读取 s_daily.progress。

分类标记写在各函数体内，禁止用一条文件级注释豁免整份文件：

- `FIXED_RESULT`：明确的固定规则、静态图鉴数据或有意退役的兼容接口。
- `PLATFORM_NOOP`：平台不适用的契约，例如浏览器不提供 Steamworks，原生端不通过浏览器事件轮询。
- `STUB`：确实未实装或未跟踪的能力，仍须如实列出；标记并不表示已经实现。

`tools/stub_scan.py` 默认检查未分类的数字/空操作候选；`--strict-stubs` 还会对这些显式 STUB 返回失败。它不会把 `return object.field` 当成常量，也不会自行展开宏或证明运行行为。仅返回大写符号的函数作为信息项列出，不猜测宏语义。

补丁补充：`--include-queries` 可额外展示普通状态查询及其实际返回表达式，例如 `collector.active`；这些信息项不计入未标记桩，也不表示已运行功能验证。
