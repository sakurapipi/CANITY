# CANITY 2.4.2 RC：交互修复与创作工作流

本轮只修改代码、编译和打包，不启动游戏、不运行测试、不提交或推送。验收由用户完成。
地图36×36、容器槽12、世界精灵容量64保持不变。显示版本仍为2.4.2 RC。

## 标准化创作
铁律AD-87～AD-90登记统一创作流程。工具为tools/creation_flow.py，配方为tools/creation_recipes.json。
覆盖怪物、投掷物、成就、局外技能、局内技能、UI，提供规格生成、文件入口和按函数选择的上下文包。
这不是“生成一个空壳就宣布完成”：实现仍须接入执行、状态、存档、展示和输入生命周期。
工具不会自动修改运行逻辑，也不会替用户运行验收或推送。参见《标准化创作工作流.md》。

## 交互与UI
- 三选一：鼠标/触屏按真实卡片矩形选择并提交；键盘确认忽略自动重复，避免连选两张。
- 关闭三选一清除输入边沿、地图遮罩和当前画面残留；切换状态时重新绘制。
- 局内40节点保持原有ID、价格、效果和前置关系，按层级与三个方向重新布局；详情区与左侧导航分开。
- 总览放不下文字的节点显示标记，选中后在详情区显示完整信息，可滚轮放大查看。绘制与点击共用尺寸。
- 已搜容器的回声标记即时清除，地图绘制时也对照实际容器复核，避免旧回声继续指示空箱。
- 高强度界面加入边缘缺口、裂纹、锈蚀和外露边框；不移动按钮、不破坏中心文字，不加强世界污染。
- 破败表现参考废弃设施的磨损层次，采用本项目自绘效果，没有复制第三方素材。
参考：[Steel Wool 官方 RUIN 介绍](https://steelwoolstudios.com/game/five-nights-at-freddys-security-breach-ruin/)。

## 小游戏与怪物
- 命中即时恢复理智和电量，电量恢复为当次理智基础恢复量的1.25倍，均受容量上限限制。
- 累计第六次失误结束小游戏并退出藏身点；前五次只断连击。取消不踢出，已恢复资源不扣回。
- 藏身点被动恢复仍在小游戏期间生效。
- 听声怪看到玩家时继续追击，不再因到达先前声音坐标提前转搜索；可见目标下卡住优先重新寻路。
- 清道夫不再受金币/强度门槛限制，保留连续藏身三次或180秒触发、离场35秒冷却；训练场不刷。
- 偷钱怪逐层提高概率：14+层数×7%，最高90%；每层一次出场判定，每局最多出现三次。
- 三次出现的偷取比例分别20%、30%、40%，按接触时当前金币计算；藏身状态不会被贴身偷取。
- 出场次数、得手次数、已判定楼层保存到v44，读档不重新发出场预算。旧档无历史计数时从零开始。
- 蜘蛛射程4.5→7格，保留视线、前摇与躲避窗口。
- 图鉴文字同步新的清道夫和偷钱怪规则。

## 主题房间
声源置换配线圈、债务密库配档案柜、灯塔配棱镜、移植舱配医疗床、换位门配控制台、疯癫契约配祭坛、借时心室配心室装置。
战役房间也按章节主题选择装置。
主题家具可进行一次明确的检修/搜取：医疗装置恢复6理智、档案抽屉12金币、其他主题装置取回8电量；用尽后不可重复刷。
普通货架与控制台保留原搜查行为。家具不冒充奖励箱；高价值奖励箱仍需解谜解锁。

## 模式与存档保护
- 战役：保留手工地图出生点与出口，资源候选从真实出生点计算；修正出生区域断开与空候选取模路径。
- 容器与电闸随机放置均增加空集合保护，异常空候选使用连通维护层兜底，避免除零崩溃。
- 暂停菜单保存后回主菜单，保留每日/战役模式以供继续；保存失败停留原界面，不伪报已保存。
- 有现存正式进度时，新普通局/无尽/战役/每日均先询问是否覆盖；默认保留，回车确认当前按钮，Y覆盖、ESC/N取消。
- 删除“新游戏入口先删旧存档”的路径。训练与引导不覆盖正式进度。
- 自动分辨率不再保存为某个固定档位，按屏幕工作区计算；全屏按屏幕尺寸，渲染质量仍由独立设置控制。
- v37～v43升级本轮时一次恢复AUTO与100%渲染比例，之后仍允许自行保存画质偏好。
- v44只在v43尾部追加偷钱怪计数；旧版程序不保证能读新档，先备份存档。
- 设置单独落盘时保留追加的运行态尾部，训练毕业奖励仍按个人档案保留。
