# A. 表现层

## A1　局内页面：阴沉的蓝 + 闪烁 + 暗角 + 胶片颗粒

- **基调**：主题蓝色，整体阴沉。
- **闪烁**：偶尔、不规律、低幅度（像灯管供电不稳），与理智档联动；是氛围，不能挡住看清路。
- **暗角增强**：三处都要做 —— ① 局内画面四周压暗；② HUD 边框加深；③ 转场用暗角收放代替硬切。
- **胶片颗粒**：复古胶片相机质感，颗粒强度随理智下降而增强，**必须有上限**（`grainMax`）。

## A2　字体：血腥感 + 精神污染
字体带血色/渗色/笔画侵蚀，风格压抑不安；**关键数值保持最高可读性**，装饰只作用于标题与氛围文本。

## A3　理智只影响观感（四档）

| 理智 | 画面 | 音乐 | 视角 |
|---|---|---|---|
| **>80%** | 完全清晰（颗粒 0、无闪烁、无畸变） | 平缓 | 稳定 |
| **80~50%** | 轻微颗粒 + 偶发闪烁 | 节奏改变、紧迫 | 稳定 |
| **50~20%** | 颗粒明显、暗角加重、色调偏移 | 更阴沉惊悚 | 开始崩坏 |
| **<20%** | 接近颗粒上限、闪烁频繁、污染字体启用 | 疯癫、临近崩溃 | 明显崩坏 |

四档过渡要平滑（插值），阈值集中定义，便于调参。

## A4　音乐扩展（素材由用户提供）
用户自行合成并导入。实现方需：预留接入位置与格式约定、支持情境切换（菜单/局内/追逐/安全屋/低理智）、与 A3 联动。
【待设计】曲目 ↔ 情境 ↔ 理智档 映射表。

## A5　金币配色修正
所有"金币/黄金"数值改为金色系（暖金），不沿用主题蓝。范围：主菜单、局内 HUD、商店、银行/结算。

### A6.1　总原则：**高成本全维度差异化**

每个主题必须在这 **6 个维度**上都有可辨识差异，**不许只改颜色**：

```
① 墙面   贴图/图案/墙高（砖缝、铁栅、肉壁脉动…）
② 地面   独立地面材质（v3 新增：地板模型允许更改）
③ 光照   照度、色温、有无频闪、主光源位置
④ 粒子   尘埃 / 水滴 / 火星 / 白雾 / 蒸汽 / 孢子
⑤ 音效   环境循环音 + 随机点缀音（v3 新增：必须有）
⑥ 事件   该主题专属的"特殊事件"（v3 新增）
```

### A6.4　**每层至多一个特殊房间**（v3 新增规则）

- 每层生成时，**最多**生成 1 个主题房间；可以是 0 个。
- 该房间即"特殊房间"，承载 A6.3 的事件。
- 其余区域保持普通走廊/房间，**不得出现第二个主题房间**。
- 生成失败（放不下/接不上门）时：**允许回退为零个**，不要为了凑数而破坏连通性。

### A6.5　特殊房间规格扩大（v3 新增）

- 现有模板上限是 **6×6**（`ROOM_MAX_W/H`），特殊房间放不下上表的尺寸。
- 需要**扩大特殊房间的规格**：
  - 特殊房间尺寸上限提升到 **9×9**（上表最大值）；
  - 模板缓冲、放置校验、连通性检查、崩溃回滚路径都要跟着改；
  - 普通小房间仍可保留 6×6 上限（避免走廊被挤没）。
- 每个主题**至少 2 个地形模板**（形状/开口位置不同），避免每次都是同一个盒子；共需 **≥14 个模板**。

### A6.6　技术约束（实现方必须遵守）

- **不新建整套材质系统**：沿用现有"每主题一套贴图 + 逐列 tint"的做法，地面允许新增**每主题地面绘制**，但不要引入运行时纹理流式加载。
- 房间生成必须是**纯数据 + 纯函数**（不碰 `worldMap`、不碰 `rand()` 的全局序列），保证可单测、失败可安全跳过。
- 现有 24×24 地图与"容器 8 / 精灵 48"上限**不变**。
- 扩大模板尺寸后，`RoomTemplateFits` 的 margin 规则（不许贴外墙）必须重新校准，并补单测。

### A6.7　验收（A6 专项）

```
[ ] 7 个主题在截图里并排可一眼区分（不看名字）
[ ] 每个主题有独立地面绘制（不是共用一套）
[ ] 每个主题有独立环境音 + 至少 1 个随机点缀音
[ ] 每个主题有独立粒子
[ ] 7 个特殊事件全部可触发、有前兆、有日志/提示
[ ] 每层生成主题房间数量 ∈ {0, 1}，跑 100 层统计不应出现 2
[ ] 特殊房间最大可达 9×9，且连通性检查通过
[ ] 每主题 ≥2 个模板，共 ≥14 个

```

# C. 玩法

## C1　校准小游戏重做为**音游**
- 空格开始；**QWER 四条校准线**；屏幕**左侧小方框**；音符**从上往下掉落**（类似钢琴块 2）。
- 音乐用**当前主题曲中间截取的片段**；做节奏采集生成谱面。
- **层数越高难度越大**。
- 累计**弹错 5 次** → 立即判负（不结算），判负后 **30 秒禁入**。
- 连击奖励：2 连 +2 理智、3 连 +3、单次**上限 +10**。
- 连续按**两下空格**退出。
- 通过**调用现有校准入口函数**接入，不另起并行逻辑。
【待设计】判定窗口、断连规则、音符生成算法、谱面格式。

## C2　取消「投石」技能 → 替换新技能
- 取消投石（它**没有动画**且占着 G 键）；
- 替换为新技能 `【待设计】`（潜行/逃生/资源/信息类，**必须有动画**）；
- 释放 **G 键**给新技能。
- 交付：中英名、效果、数值、技能树位置、G 键行为、视觉方案。

## C3　修整服务：按百分比付费 + CD
- 价格与**当前理智**挂钩，**理智越低越贵**（用户示例：理智 30→60 金币、理智 50→30 金币，**仅示意方向**）；
- 价格由曲线/公式推导，禁止写死；**必须有价格预览**；【待设计】曲线与 CD 时长。

## C4　商店刷新键
新增刷新键（避开现有按键），**冷却 60 秒**，CD 内提示剩余秒数。

## C5　技能树扩展 + 结构重画
- 现有 3 条分支：**北 / 西南 / 东南**；**画一条主干线**串起三条分支；
- 分支节点 = 流派技能；主干线旁**三片空白区**放通用技能与弱关联技能；三区**颜色区分**、各有特点；
- 技能树**向外扩展**；【待设计】总节点数、三区内容与配色；
- 附带修复：节点短名从 1 字改 **2~3 字**（现在界面上全是「静/轻/夜」）。
