# 三途技能网与怪物档案：本地改造交接

本轮只改源码、检查器源码和说明。没有编译、启动游戏、执行测试或检查器，没有提交或推送。修改前源码备份为 `CANITY-before-gameplay-redesign`；用户继续负责验证与发布。

## 怪物档案

目录与档案双栏取代旧通用菜单。七个历史 ID 不重排，其中六个是现行图鉴，旧跳脸怪保留档案但不参与现行收集。蜘蛛、水蛭的实体仍保留；它们不是现行六类图鉴的替身，本轮未把它们强塞进旧存档位。

七个肖像显式对应游戏已经烘焙的实际资源：听声鬼、追光鬼、旧跳脸怪、拾荒者、清道夫、守门人、宝箱怪。原表的 spriteId 全部为 0，现已改成具体 SPR_*。拾荒者使用历史上复用的 LEECH 槽位，守门人使用复用的 SPIDER 槽位；不是用水蛭/蜘蛛的模型冒充它们。原模型和烘焙几何不改。

未遭遇显示暗色剪影；遭遇后显示肖像、身份、危险度和战绩，研究分阶段揭示行为与对策。文本按 UTF-8 完整字符换行，各区有明确边界；鼠标目录命中只落在左栏，阅读右栏不会误点返回。

## 局外三途技能网

中心 ORIGIN；幽灵向北，掠夺者向西南，反击者向东南，通用/交叉节点连接三角形内部。40 个玩家节点与第 41 个内部定义不混用。位置、方向导航和命中都读取同一节点数据；HOME 展示全图，小比例用缩写，放大与详情用于阅读。

前置真实重接线：反击者不再要求购买幽灵王冠。流派投入门槛使用三种实际分类，而不是旧四列/风险列的标签。双前置连线全部绘制，购买仍检查两端。局外只扣银行金币；既有技能 ID、等级和拥有记录保留。三个流派王冠的效果统一检查当前装备王冠，防止拥有三顶就同时生效；切换提示与 2000 银行金币费用一致。

## 局内三途改造网

保留 20 个节点的存档位及实际效果。省电/电量向北、行动/体能向西南、抗性/理智向东南，扳手链位于内部。原顶点二选一保留；方向导航可以到达替代顶点，鼠标与键盘共用真实坐标。新增明确购买按钮，点击选择后可以用鼠标购买。

只使用 WalletSpendRun，不访问银行。每局开始清空，本局存档继续保留。基础/二级/三级/顶点价格调整为 90/180/320/550；此为新平衡初值，尚无实测结论。旧节点已经拥有时不追扣差价，重置按当前价格退款，不伪造历史成交价。

局内改造网与每两层的技能卡草案是不同入口。本轮重做的是安全屋改造网，保留现有技能卡/遗物奖励流程，未擅自删除这些内容。

## 经济与怪物压力

- 金币档位阈值重写为 0/150/350/650/1000/1500/2200/3100/4300/5800/7800/10500/14000/18500/24500/32000。
- 金币只增加感知压力和原档位机制，不直接乘怪物移动速度。金币听觉压力与构筑听觉压力相加，合并上限 2 倍；战役独立修正仍保留。
- 威胁增量报价与实际购买共用 ThreatCostForTier：0.5/0.8/1.2/2.0，修复原 UI 显示 1/2/3/3 的不一致。
- ThreatRatio 与 ThreatValue 使用同一有效值；读档先恢复技能，再剥离已包含的 GREEDY HAND 加成，避免重复累加。
- 听声鬼/追光鬼从统一速度计算取得当前威胁效果，每次更新读取当前构筑；最终硬顶统一为 2.20，第三只变体倍率在最终夹取之前计算。
- HUD 的旧 BOOST 实际是钱包历史占比，却被译为“强度”，已改成综合压力与下一金币档阈值。
- 所有分散的金币收入转入钱包边界；负价拒绝、整数饱和、取款不损毁无法携带的金额。结算预览与实付共用收益函数，防止高余额浮点转 int 溢出。
- 满电、满理智、非法补给类型均不扣款；背包与资源回复分别判断收益。

这些是数值设计与代码修改，不代表难度/收入已由真实游玩校准。

## 成就逐项梳理的处理

32 个条目、存档槽位和 Steam API 名称保留，成就 UI 不改。旧 API 名中的 7/300K 等历史字样为外部身份，不改名以避免丢进度；显示文案使用当前定义。

1–8 进程条件仍对应首次开局、撤离、层数和时长。旧 FIRST STEPS 的硬编码补发已清理。
9–11 携带金币门槛改为 1000/5000/15000，与局内经济相配。
12 追回赃款保留真实事件，13 存钱罐改为余额达到 20000 并明确是余额，14 零被抓撤离保留。
15–21 满理智撤离、击退、投掷、守门人三层、回声探索、不开箱和无光仍读真实记录，清除按旧数字编号补发的路径。
22 威胁满值仍为 18；23–25 遭遇一类/三类/全部六类现行图鉴，排除旧跳脸怪。
26 点亮 30 个玩家节点，移除曾用“普通技能全满”提前解锁的替代条件。
27 守门人视野撤离保留；28 双重追捕现在要求两只真实听声鬼处于追捕状态，旧逻辑误查搜寻状态并混入一只追光鬼。
29 第十二层携带门槛改为 12000；30 重置改用有名事件路由；31 图鉴研究改为六类均达到对策阶段；32 全程藏匿追捕记录有局生命周期复位，不能中途进柜就声称躲过整场。

已解锁标志不撤回；未解锁的旧“全遭遇”进度不冒充新“全研究”完成度。特殊条件通过带名字的稳定 AchFlag 路由，不再到处写裸数字。
