# CANITY v2.5.0 RC5

- 「死寂」按声音类别计算传播。慢走降低脚步声，冲刺、搜查和手摇增加声音，怪物听觉独立计算。
- 「积水回廊」改用连贯的浅水带。水面不改变墙体或玩家移动速度。
- 新版会拒绝无效的事件档案和无法理解的已知扩展格式，并保护原档。未知扩展仍会原样保留。
- 旧八层剧情进行中存档会先做字节一致的独立归档。玩家确认迁移后可继续使用银行与角色档案。B-17 三章与普通跑局按原有路径读取。存档主体仍为 v46。

## 恢复旧八层剧情

退出游戏。保留当前存档的副本，把带有 `.retired-story` 的归档复制到 [RC3](https://github.com/sakurapipi/CANITY/releases/tag/v2.5.0-RC3) 的独立存档目录，并将副本命名为对应的 `canity0.sav`、`canity1.sav` 或 `canity2.sav`。浏览器版归档保留在站点存档存储中，恢复时需导出归档存档键的副本再导入 RC3 的独立环境。

本版为预发布。角色单价为每人 10,000 银行金币，事件收益与怪物速度硬顶沿用既有规则。正式版平衡评估仍需真实通关、移动端和性能采样。
