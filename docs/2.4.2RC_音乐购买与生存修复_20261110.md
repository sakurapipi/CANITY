# CANITY 2.4.2 RC — 音乐、购买与生存修复

本轮只修改代码、转换音频、编译及打包，没有启动游戏、运行测试或验收，没有提交或推送。请由用户使用本轮源码和运行包重新验收。

## 本轮变更

- 清道夫不再寻找、翻开或消耗箱子，右侧“清道夫在翻你的箱子”字幕已删除。保留追踪玩家和检查藏身点的反蹲守行为。
- Windows 原生鼠标分支优先处理局内技能树购买按钮，避免被画布拖拽接管；点击节点按当前前置、金币和互斥规则直接尝试购买。网页共用同样的购买入口，回车和空格不变。
- 普通新局不再预先删除存档或改写模式标记。先进入统一覆盖确认，取消保留现有进度，确认后才初始化新局。
- 低电量技能只在关灯时涓流回充；藏身点的自然充电也要求关灯。开灯时不会再被这两类被动回充抵销耗电。摇电、拾取电池、小游戏正确按键等主动恢复保留。
- 耗电倍率读取已夹取的技能等级，并检查异常/非正值；消耗不会因负倍率变为恢复。
- “代谢”不再将全部自然理智流失转为电量：只转换一半，另一半仍扣理智。转换部分按1:3耗电，电量不足时缺口按饥饿惩罚处理；安全区和藏身时不收这笔自然消耗。技能说明同步更新。
- 理智消耗统一检查倍率有效性；新局重置反击窗口、站立计时和典当冷却。保留训练场免扣、短时机制、安全区恢复、小游戏奖励。最后救援仅在理智实际归零时触发。
- 本地配乐优先 MP3，使用随包解码器进入原有混音链，保留理智音色处理、暂停及场景切换，不要求系统另装解码器。只在进入场景时解码并回收不用的缓存，不再预载整套WAV。
- 网页优先 MP3，保留旧WAV回退与合成兜底；加载失败不会永久缓存失败结果，清理非当前场景的解码缓存。仍需要浏览器允许声音，首次点击后才可播放。
- 六首配乐WAV母版约77.2MB，转换后的MP3约7.0MB；运行包仅包含MP3。WAV母版保留在Source/music供后续创作，不加入本轮源码ZIP的重复音频。

## 兼容与输出

保留版本2.4.2 RC、存档v44、地图36×36、12容器槽及64世界精灵容量。Game/saves原有存档不替换。所有交付、备份和工作记录均放在桌面GAME。

打开根目录“开始游戏.bat”运行。Web为网页/手机触控文件，需要HTTP服务，非APK。

MP3解码器来源：https://github.com/lieff/minimp3 （CC0；固定版本见third_party/minimp3/minimp3-source.txt）。第三方代码与游戏代码隔离，构建缓存已纳入其头文件指纹。
