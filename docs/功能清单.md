### 2.2 技能树结构

```
节点排布     8 列 × 6 行（48 槽位，40 已占，余 8 空位）
分支         5 条（branch 0~5）
每节点等级   1~5 级（maxRank）
总花费       SKILL_TOTAL_COST
```

**加一个新技能 = 一条命令**：

```bash
python tools/content_gen.py skill --en X --zh Y --short Z --cost 2600 --apply
```
自动改 7 处（枚举 / `SKILL_COUNT` / 总价 / 表行 / 坐标 / 短名 / `kSkillList`），写完立刻自检。

**成就墙**：5 个分类 + 全部，TAB / Q / E 切换筛选。

**历史坑（代码注释已记录）**

```
flags[8] → flags[16]
原因：AK_FLAG 的 target 用到 14，
      原先 target 2~7 走 flags[2..7]、target 10~14 又走 flags[2..6] ——
      两组成就共用一个槽，"解了 A 连带解 B"。
现状：已扩到 16，target 直接当下标。
遗留：老存档里的位没有迁移逻辑。
```
