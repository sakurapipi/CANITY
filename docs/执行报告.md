## 四、过程中真正踩到的坑（比结果更值钱）

1. **段范围重叠**（第 3 轮）：hatch 段按"从计时器到 HatchPlaceInRoom 结尾"取，
   把夹在中间的 collapse 整段也圈进去了 → 两个文件都定义 `Collapse*`。
   回滚重来，改成按真实布局分五段 + 段间不重叠断言。
2. **跨域读私有变量**：`game.c` 里 `extern int collapseArmed;` + `|| collapseArmed`，
   定义搬走后链接失败。改成调契约里本来就有的 `CollapseBusy()`。
3. **跨域标志位**：`s_collapseGen`（collapse 写、game.c 读）必须进契约头且不能 static。
4. **分区契约 S1 拦了两次**：`phase.c` 的 `<math.h>`、`rng.c` 的 `<stdlib.h>`。
   规则不是形式主义 —— 系统头扩散后，换平台（Emscripten）就会到处炸。
5. **`DT_NONE` 不存在**：common.h 只有 `DT_SLASH/BLUNT/SHARD`，用 -1 当哨兵。
6. **锚点匹配凭记忆写**：有牙验证脚本第一次报"锚点没找到"，因为表行的空格数和我记的不同。
   锚点必须从文件里读。

## 四·补、第 7 轮第二批为什么回滚了

试过把「成就页 + 文本裁剪」再切一块出去（`ClampRowText` 14 行 + `DrawAchievementsWindow` 177 行）。
切到一半发现：成就页依赖 `AchGeo` / `AchCompute` —— 而**菜单命中测试也用同一个几何缓存**。
把它们一起搬走就等于开始动"交互状态"，那已经越过"整理结构"的界线了。

回滚了整批，`git status` 回到干净状态，`build_validate` 回到 12757。
结论：UI 的下一刀不是"再切一块文件"，而是**先把几何缓存与命中测试解耦**，
那需要单独一轮 + 每个页面各一张截图做回归。写在这里，避免下次又从头试一遍。
