# A. 表现层

## A1　局内页面：阴沉的蓝 + 闪烁 + 暗角 + 胶片颗粒

- **基调**：主题蓝色，整体阴沉。
- **闪烁**：偶尔、不规律、低幅度（像灯管供电不稳），与理智档联动；是氛围，不能挡住看清路。
- **暗角增强**：三处都要 —— ① 局内画面四周压暗；② HUD 边框加深；③ 转场用暗角收放代替硬切。
- **胶片颗粒**：复古胶片质感，强度随理智下降增强，**必须有上限**（`grainMax`）。

## A2　字体：血腥感 + 精神污染
血色/渗色/笔画侵蚀，压抑不安；**关键数值保持最高可读性**，装饰只作用于标题与氛围文本。

## A3　理智只影响观感（四档）

| 理智 | 画面 | 音乐 | 视角 |
|---|---|---|---|
| **>80%** | 完全清晰（颗粒 0、无闪烁、无畸变） | 平缓 | 稳定 |
| **80~50%** | 轻微颗粒 + 偶发闪烁 | 节奏改变、紧迫 | 稳定 |
| **50~20%** | 颗粒明显、暗角加重、色调偏移 | 更阴沉惊悚 | 开始崩坏 |
| **<20%** | 接近颗粒上限、闪烁频繁、污染字体启用 | 疯癫、临近崩溃 | 明显崩坏 |

四档过渡平滑（插值），阈值集中定义。

## A4　音频需求（**最终版 · 全部要求在此**）

### A4.0　总目标：**惊悚、吓人**

这是恐怖逃生游戏，音频的第一目标是**制造惊吓与不安**，不是"好听"、不是"氛围铺底"。
判断标准只有一条：**玩家戴耳机玩十分钟，会不会觉得背后有东西。**

具体要求：
- 要有**突然的、不可预期的高频刺激**（stinger / 突然的金属刮擦 / 猝发的低频冲击）；
- 要有**持续的、低频的压迫**（sub-bass drone、心跳、地下管道共鸣）；
- 要**留白**：安静比吵闹更吓人，吓人点之前必须先安静下来；
- **不许用轻音乐/明亮和弦/欢快节奏** —— 任何"温馨"的音色都是错的。

### A4.1　现状（实现方先复核）

```
src/audio.c   850 行：音效由 GenSounds() 在启动时**代码合成**，直接 waveOutWrite
src/music.c   155 行：优先加载 music\*.mp3 / *.wav；找不到则用内置程序化配乐
              （CANITY_MUSIC=builtin / files 可强制）
```

当前发布的包**没有 music 目录** → 实际播放的是程序内合成的配乐（质量有限）。

### A4.2　音乐：文件化的六首（**必须严格按此命名**）

代码里写死的文件名（`src/music.c:135`），不许改名：

```
music/menu.mp3     或 music/menu.wav      主菜单
music/explore.mp3                          局内探索
music/chase.mp3                            被追击
music/safe.mp3                             安全屋
music/victory.mp3                          胜利/结算
music/defeat.mp3                           失败
```

**扩展要求**：
- 音频素材**由用户提供**（用户会自行合成并导入）。实现方负责**接入、切换、混音**；
- 若某首歌缺失 → 自动回落到内置程序化配乐（现有逻辑保留，不许删）；
- 新增曲目（如"低理智"变体）**沿用同一套命名约定**，并在文档写明。

### A4.3　格式规范（硬性）

```
采样率      44100 Hz
位深        16-bit
声道        立体声（2ch）
WAV         未压缩 PCM（体积大但零解码风险）
MP3         码率 ≥ 192 kbps，CBR
循环        必须**无缝循环**：首尾采样对齐，不许有淡入淡出尾巴
电平        峰值 ≤ -1 dBFS，不许削波；RMS 控制在 -18 ~ -14 dBFS
时长        单曲 60~180 秒（menu 可更短）
```

### A4.4　音效：**继续用代码合成**（不许引入外部音效文件）

- 现有 `GenSounds()` 的合成路线**保留**；
- 新增音效（主题房间/怪物/事件）也必须**代码合成**，理由：不增加包体积、不依赖外部资源、可参数化；
- **音频回调里不许 malloc / 不许文件 IO / 不许加锁等待**（RT 安全），所有波形必须在启动或进入场景时预生成；
- 合成器要能产出这几类音色（供各系统调用）：
  ```
  低频冲击 / 心跳 / 金属刮擦 / 滴水 / 蒸汽泄放 / 电流嗡鸣
  生物蠕动 / 骨骼摩擦 / 玻璃裂 / 门轴吱呀 / 呼吸
  ```

### A4.5　与理智档（A3）联动

- **不许为四个档位各做一首曲子**（体积爆炸）；
- 用**同一曲目 + 实时处理**实现递进：低通滤波随理智下降而降低截止频率、加轻微失谐、加噪声层、加快心跳层；
- 处理必须在音频线程内可实时运算，不许每帧重建缓冲。

### A4.6　混音与优先级

```
优先级   音效 > 追逐音乐 > 环境音乐
闪避     "music ducking" 已存在（duckTime / duckGain），
         重要音效（怪物近身、被抓）触发时必须压音乐，不许淹没音效
总线     主音量必须受设置项（44 项设置里的音量项）控制，不许绕过
暂停     暂停时音乐必须淡出（现有 paused → target 0 的逻辑保留）
```

### A4.7　音游对接（C1 依赖）

- 音游需要**节奏清晰的曲目**，用主题曲**中间截取的片段**（30~60 秒）；
- 实现方要做**节奏采集**（onset 检测 / 节拍估计），把谱面数据随包发布；
- 谱面数据格式由实现方设计，但必须**可离线复现**（同一首歌 → 同一份谱面）。

### A4.8　版权与来源

- 所有音乐素材必须**原创或已获授权**，不许使用任何版权曲目；
- 素材来源与授权情况必须写进 `docs/`（用户提供的素材由用户负责声明）。

### A4.9　验收（音频专项）

```
[ ] 六个文件名与代码一致，缺失时能自动回落到内置配乐
[ ] 每首歌无缝循环（连听 3 遍听不出接缝）
[ ] 无削波、无爆音、无突然的音量跳变
[ ] 追逐曲与探索曲气质明显不同（盲听可辨）
[ ] 吓人点存在（至少 3 处 stinger），且都发生在"安静之后"
[ ] 理智四档能听出递进（同一首歌，处理不同）
[ ] 音效优先级正确（怪物近身时音乐被压下去）
[ ] 音频线程无 malloc / 无文件 IO
```

## A6　**主题房间：重新设计（由实现方自行设计）**

### 现状问题
现有 7 个主题房间（砖墙 / 监狱 / 地狱 / 病房 / 冰窖 / 锈工厂 / 血肉洞窟）差异化不足：
基本只靠"墙面色 tint + 一个家具特征"区分，玩家走进去只看到"一个方盒子换了颜色"。

### 要求

1. **全部重新设计。**
   主题名单、每个主题的视觉风格、地面、光照、粒子、音效、房间内的**机制与特殊事件**，
   **全部由实现方自行设计**。不要沿袭现有 7 个，也不要只换配色。

2. **主题房间的选取要和"这一层的整体场景主题"挂钩。**
   每层本身有场景主题；生成主题房间时由**该层的场景主题决定出现哪一种主题房间**（匹配关系由实现方设计），不许随机乱配。

3. **每个主题房间里必须有「总控闸」。**
   - 可交互构件；
   - 触发后承接**既有的「崩塌」流程**（整层地形重掷）；
   - 既有实现必须保留并复用 `src/domain/collapse/collapse.c`：
     淡出抖动 → 黑屏 → 重掷 → 玩家脱困 → 淡入；不可通关则回滚并提示"这里塌不动"；崩塌层不再生成新舱门。

4. **每个主题房间必须设计得不一样。**
   不许两个主题共用同一套机制或同一个特殊事件；不许"只换颜色"。

5. **连通性与死路可控。**
   生成后必须保证全图可达；死路不能过多（阈值与测量方法由实现方提出，并落地成可跑断言）。

6. **数量与回退。**
   每层**至多 1 个**主题房间（可 0 个）；生成失败允许回退为零，不得破坏连通性；崩塌重掷后同样满足"至多 1 个"。

### 交付物（必须写进报告）

```
· 主题清单：几种、每个叫什么、各自动机（一句话）
· 每个主题：视觉 / 地面 / 光照 / 粒子 / 音效 / 房间机制 / 特殊事件
· 主题房间 ↔ 层场景主题 的匹配规则
· 总控闸的交互流程，以及如何衔接崩塌
· 每个主题的验收方式
```

### 约束
- 不新建整套材质系统（不引入运行时纹理流式加载）；
- 房间生成保持"纯数据 + 纯函数"，可单测、失败可安全跳过；
- 24×24 地图、"容器 8 / 精灵 48"上限不变；
- 沿用现有逐列 tint 机制，不要每像素重算。

# C. 玩法

## C1　校准小游戏重做为**音游**
- 空格开始；**QWER 四条校准线**；屏幕**左侧小方框**；音符**从上往下掉落**（类似钢琴块 2）。
- 音乐用**当前主题曲中间截取的片段**；做节奏采集生成谱面（见 A4.7）。
- **层数越高难度越大**。
- 累计**弹错 5 次** → 立即判负（不结算），判负后 **30 秒禁入**。
- 连击奖励：2 连 +2 理智、3 连 +3、单次**上限 +10**。
- 连续按**两下空格**退出。
- 通过**调用现有校准入口函数**接入。
【待设计】判定窗口、断连规则、音符生成算法、谱面格式。

## C2　取消「投石」技能 → 替换新技能
- 取消投石（**没有动画**且占着 G 键）；
- 替换为新技能 `【待设计】`（潜行/逃生/资源/信息类，**必须有动画与音效**）；
- 释放 **G 键**给新技能。
- 交付：中英名、效果、数值、技能树位置、G 键行为、视觉与音效方案。

## C3　修整服务：按百分比付费 + CD
- 价格与**当前理智**挂钩，**理智越低越贵**（示例：理智 30→60 金币、理智 50→30 金币，**仅示意方向**）；
- 价格由曲线推导，禁止写死；**必须有价格预览**；【待设计】曲线与 CD 时长。

## C4　商店刷新键

## C5　技能树扩展 + 结构重画
