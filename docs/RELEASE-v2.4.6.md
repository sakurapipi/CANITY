# CANITY v2.4.6 正式版

本版专注存档可靠性，保持 v45 存档结构、36×36 地图、12 个容器槽和现有玩法。

## 修复

- 删除事务恢复时，目标内容不同或恢复写入不完整均返回错误，保留 PREPARED 日志和原始恢复数据，不覆盖另一份进度。
- 云冲突标记写入失败不再跳过冲突快照；两个保存动作分别尝试并记录错误。
- 每次进程启动重新建立云同步许可。标记不存在不代表允许上传；本地与云端不同则必须明确选择版本。重启不能绕过未解决冲突。
- 正常保存前重新读取远端，与本次会话确认的字节比较；远端变化则暂停上传并保留双方。自动上传前保留不可覆盖的远端快照。
- 已有本地档备份或替换失败时停止安装，不通过备用目录激活另一份进度。
- 恰好 64 个存档块可以读取、修改、保存和再次读取；不会重复计入已有的兼容块。
- 对已知块 SETTINGS、LOBBY、RUN、WORLD、LEGACY29 明确只接受 schema 1；未知块保留原始 schema、顺序和字节。
- 本地和云端统一校验信封、块表及内部存档；统一 16 MiB 上限、不可覆盖快照及错误诊断。

## 云端行为变化

存在两份不同的有效进度时，不再仅凭时间戳自动取胜。用户可选择本地、云端或暂缓；暂缓不影响本地继续保存，但不覆盖远端。读取远端与写入远端之间 Steam API 不提供原子比较交换，本版仍不能承诺两台设备在同一瞬间写入时的服务端事务隔离；上传前快照用于保全已读取版本。

## 下载与使用

Windows Lite 包完整解压后双击 canity.exe，保留 music/ 和许可证；不需要 DAT。网页版与手机共用在线页面，也提供网页 ZIP 与单文件 HTML。

## 验证与范围

本地桌面完整验证通过：146 个编译/验证阶段零失败，15 个运行域全通过；云同步/删除故障回归、23 项维护工具测试、结构及耦合检查通过。普通/单文件 Web 构建通过，Edge 浏览器专项 33/33 通过。发布流程随后对标签提交重新编译并验证。最终源码 SHA 和附件哈希以发布构建记录及 build-manifest.json 为准。

新增用例包括恢复目标冲突、恢复写入中断重试、云标记写入失败仍保留快照、全部写入失败后模拟重启、会话内远端变化、64 块完整往返及已知 schema 拒绝。

公开包为未启用 Steam SDK 的 Lite 构建；云存档测试使用真实后端配合内存文件系统和 Steam 替身，不是 Steam 双设备实机验收。浏览器测试使用 Edge 模拟触控，不代表实体手机验收。
