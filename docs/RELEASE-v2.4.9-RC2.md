# CANITY v2.4.9-RC2

基于 [v2.4.9-RC1](https://github.com/sakurapipi/CANITY/releases/tag/v2.4.9-RC1) 的预发布修复版。

- 读取扩展存档时验证共享声源索引，存档主体仍为 v45，原有扩展块格式继续兼容。
- 战术道具成功使用后才进入冷却。投掷池已满或没有有效目标时保留道具，可立即重试。
- 缚丝蛛直接命中仍施加普通束缚。高档位双锚攻击落空时生成连续减速区，持续 2.5 秒。
- 声源诱导井先按实际发声点计算降噪，再把声音转移到井口。
- 新局可用 J、U、O、L 选择四个快捷槽。已有自定义游戏按键优先，继续游戏保留已保存的快捷槽设置。
- 商店参考当前楼层的怪物出场条件备货，玩家可在部分怪物实际出现前购买反制工具。

吸声胶囊基础半径为 3 格，持续 10 秒，脚步降噪 80%，其他新噪声降 70%。断光棱镜基础致盲 3 秒。局内强化仍可增加范围或时长。威胁档位继续使用冷蓝、蓝紫、琥珀黄和血红。

Windows 包解压后运行 `canity.exe`，保留同目录的 `music/`。网页版 ZIP 可用 HTTP 服务运行，也可下载单文件 HTML。构建清单记录了提交和发布附件的 SHA-256。
