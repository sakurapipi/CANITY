# A. 表现层

## A1　局内页面：阴沉的蓝 + 闪烁 + 暗角 + 胶片颗粒

- **基调**：主题蓝色，整体阴沉。
- **闪烁**：偶尔、不规律、低幅度（像灯管供电不稳），与理智档联动；是氛围，不能挡住看清路。
- **暗角增强**：三处都要 —— ① 局内画面四周压暗；② HUD 边框加深；③ 转场用暗角收放代替硬切。
- **胶片颗粒**：复古胶片质感，颗粒强度随理智下降增强，**必须有上限**（`grainMax`）。

## A2　字体：血腥感 + 精神污染
血色/渗色/笔画侵蚀，压抑不安；**关键数值保持最高可读性**，装饰只作用于标题与氛围文本。

## A3　理智只影响观感（四档）

| 理智 | 画面 | 音乐 | 视角 |
|---|---|---|---|
| **>80%** | 完全清晰（颗粒 0、无闪烁、无畸变） | 平缓 | 稳定 |
| **80~50%** | 轻微颗粒 + 偶发闪烁 | 节奏改变、紧迫 | 稳定 |
| **50~20%** | 颗粒明显、暗角加重、色调偏移 | 更阴沉惊悚 | 开始崩坏 |
| **<20%** | 接近颗粒上限、闪烁频繁、污染字体启用 | 疯癫、临近崩溃 | 明显崩坏 |

四档过渡平滑（插值），阈值集中定义。

## A4　音乐扩展（素材由用户提供）
用户自行合成导入。实现方需：预留接入位置与格式约定、支持情境切换（菜单/局内/追逐/安全屋/低理智）、与 A3 联动。
【待设计】曲目 ↔ 情境 ↔ 理智档 映射表。

## A5　金币配色修正
所有"金币/黄金"数值改为金色系（暖金），不沿用主题蓝。

## A6　**主题房间：重新设计（由实现方自行设计）**

### 现状问题
现有 7 个主题房间（砖墙 / 监狱 / 地狱 / 病房 / 冰窖 / 锈工厂 / 血肉洞窟）差异化不足：
基本只靠"墙面色 tint + 一个家具特征"区分，玩家走进去只看到"一个方盒子换了颜色"。

### 要求

1. **全部重新设计。**
   主题名单、每个主题的视觉风格、地面、光照、粒子、音效、房间内的**机制与特殊事件**，
   **全部由实现方自行设计**。不要沿袭现有 7 个主题，也不要只换配色。

2. **主题房间的选取要和"这一层的整体场景主题"挂钩。**
   每层本身有一个场景主题（层主题）；生成主题房间时，
   要**由该层的场景主题来决定出现哪一种主题房间**（匹配关系由实现方设计），
   而不是随机乱配。

3. **每个主题房间里必须有「总控闸」。**
   - 可交互构件；
   - 触发后承接**既有的「崩塌」流程**（整层地形重掷）；
   - 既有实现必须保留并复用：`src/domain/collapse/collapse.c`
     （淡出抖动 → 黑屏 → 重掷 → 玩家脱困 → 淡入；
      不可通关则回滚到原层并提示；崩塌层不再生成新舱门）。

4. **每个主题房间必须设计得不一样。**
   不允许两个主题共用同一套机制或同一个特殊事件；不允许"只换颜色"。

5. **连通性与死路要可控。**
   生成后必须保证全图可达；死路不能过多（具体阈值与测量方法由实现方提出并落地成可跑的断言）。

6. **数量与回退。**
   每层**至多 1 个**主题房间（可以为 0）；生成失败时允许回退为零个，
   不得为凑数破坏连通性。崩塌重掷后同样要满足"至多 1 个"。

### 交付物（实现方必须给出，且写进你的报告）

```
· 主题清单：几种、每个叫什么、各自的定位（一句话）
· 每个主题：视觉 / 地面 / 光照 / 粒子 / 音效 / 房间机制 / 特殊事件
· 主题房间 与 层场景主题 的匹配规则
· 总控闸的交互流程，以及它如何衔接「崩塌」
· 每个主题的验收方式（怎么判断"这个主题确实和别的不一样"）
```

### 约束

- 不新建整套材质系统（不引入运行时纹理流式加载）；
- 房间生成保持"纯数据 + 纯函数"，可单测、失败可安全跳过；
- 24×24 地图、"容器 8 / 精灵 48"上限不变；
- 沿用现有的逐列 tint 机制，不要每像素重算。

# C. 玩法

## C1　校准小游戏重做为**音游**
- 空格开始；**QWER 四条校准线**；屏幕**左侧小方框**；音符**从上往下掉落**（类似钢琴块 2）。
- 音乐用**当前主题曲中间截取的片段**；做节奏采集生成谱面。
- **层数越高难度越大**。
- 累计**弹错 5 次** → 立即判负（不结算），判负后 **30 秒禁入**。
- 连击奖励：2 连 +2 理智、3 连 +3、单次**上限 +10**。
- 连续按**两下空格**退出。
- 通过**调用现有校准入口函数**接入。
【待设计】判定窗口、断连规则、音符生成算法、谱面格式。

## C2　取消「投石」技能 → 替换新技能
- 取消投石（**没有动画**且占着 G 键）；
- 替换为新技能 `【待设计】`（潜行/逃生/资源/信息类，**必须有动画**）；
- 释放 **G 键**给新技能。
- 交付：中英名、效果、数值、技能树位置、G 键行为、视觉方案。

## C3　修整服务：按百分比付费 + CD
- 价格与**当前理智**挂钩，**理智越低越贵**（用户示例：理智 30→60 金币、理智 50→30 金币，**仅示意方向**）；
- 价格由曲线推导，禁止写死；**必须有价格预览**；【待设计】曲线与 CD 时长。

## C4　商店刷新键
新增刷新键（避开现有按键），**冷却 60 秒**，CD 内提示剩余秒数。

## C5　技能树扩展 + 结构重画
- 现有 3 条分支：**北 / 西南 / 东南**；**画一条主干线**串起三条分支；
- 分支节点 = 流派技能；主干线旁**三片空白区**放通用技能与弱关联技能；三区**颜色区分**；
- 技能树**向外扩展**；【待设计】总节点数、三区内容与配色；
- 附带修复：节点短名从 1 字改 **2~3 字**。
