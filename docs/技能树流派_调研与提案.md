# 技能树流派设计 · 调研与提案

> 2026-11-08。针对「以前设计的三个流派现在不明显」这件事做的诊断 + 提案。

---

## 一、诊断：为什么流派感没了

### 1.1 硬数据

| 指标 | 数值 | 来源 |
|---|---|---|
| 节点总数 | 30 | `SKILL_COUNT`（common.h:883） |
| 分支 | 5 条（SILENCE / ECONOMY / CONCEAL / SHAPE / RISK）+ CROSS + ORIGIN | `kBranchName`（ui.c） |
| 买满总价 | 160,000 金 | `tools/balance_report.py` |
| 单局收入 | ≈ 2,433 金 | 同上 |
| 买满需要 | ≈ **66 局** | 计算 |
| **"改变玩法"的节点** | **约 5 个**（DECOY / METABOLISM / PLAY DEAD / SHORTCUT / LIGHTLESS） | 表内逐条看 |
| 其余 25 个 | **纯倍率**（噪声 -35% / 金币 +25% / 理智 +30 / 电量 +20 …） | 同上 |

### 1.2 三条病根

**① 90% 的节点是"更多"，不是"另一种玩法"**
`+25% 金币` 和 `+30% 理智` 之间没有策略差异 —— 玩家只会选"这局缺什么"，
而缺什么由随机掉落决定，不由玩家决定。**这是流派感消失的主因。**

**② 王冠节点（capstone）可以免费换来换去**
`include/skills.h` 的注释写着「换 keystone：卸下旧的 + 花 3 核心 + 买新的」，
但 `SkillSwitchKeystone()` 的实现只有两行：

```c
if(!SkillSwitchable(id))return 0;
activeKeystone=id;return 1;
```

**没有任何扣费**。`SkillSwitchable()` 只检查"已拥有 + 不是当前"。

所以：买下 8 个王冠之后，切换**完全免费**。最终所有人都拥有全部玩法，
分支变成装饰 —— 而且头注释和实现不一致（这是文档债，也是个真 bug）。

**③ 分支之间效果重叠**
- SILENCE（沉寂：降噪）和 CONCEAL（藏匿：躲藏）都在解决"不被发现"
- ECONOMY（节流：金币）和 RISK（冒险：赌金币）都在解决"钱"
- SHAPE（塑形）名字抽象，玩家看不出它是什么流

**④ 总价 16 万 = 66 局，但节点价格是线性的**
30 个节点里 20 个是 `1300 / 2600 / 3900` 三档，玩家在约第 20 局就能把
一条分支点满 —— 之后 40 多局都在点"别的分支的倍率"，没有新的玩法出现。

## 二、调研结论（[Design Codex · Skill Trees](https://hayao.dev/docs/codex/system-skill-trees)）

> **「没有排他性的技能树只是一个购物清单。如果玩家最终会拥有每个节点，
> 分支就是装饰 —— 要么加稀缺，要么加对立。」**

它的调参建议，逐条对 CANITY：

| 原则 | CANITY 现状 | 判定 |
|---|---|---|
| 一局能买下 40~70% 的树 | 66 局买满 → 一局买不到 2% | ❌ **稀缺过头，等于没有选择** |
| **至少王冠节点必须排他** | 可花 3 核心随便换 | ❌ **流派必然收敛** |
| 每个分支要有一个"我为什么来这"的王冠 | 有 8 个 keystone，但都只是倍率 | ⚠️ 形似神不似 |
| 避免"陷阱节点"（严格更差的） | 未知（没测过） | — |
| 避免"神节点"（人人都点） | 未知 | — |
| 洗点要便宜 | R×2 免费洗，换 keystone 3 核心 | ✅ 合格 |

**两条结论**：
1. **稀缺不是不够，是过头了** —— 66 局买满意味着"我这辈子都在点同一个方向"，看似有选择实则没机会改。
2. **真正的病是王冠不排他 + 节点全是倍率**。

## 三、提案：三个真正的流派

设计原则：每个流派要有**一个改变玩法的核心动作**，而不是一堆 +N%。
三个流派的王冠**互斥**（同时只能持有一个）。

### 流派 A · 幽灵（GHOST）—— 不被看见

> 幻想：「我不打，也不躲，我**走过去**。」

| 节点 | 效果 | 性质 |
|---|---|---|
| 呼吸同步 | 静止 2 秒后理智不再流失 | 改变行为（站着不动变成策略） |
| 影步 | 烟里冲刺不发声 | 组合 |
| 静默落地 | 停步 3 秒后，脚步完全没有声音 | 改变行为 |
| **王冠：无形** | 静止 3 秒进入"隐形"：怪看不见你，**但你也看不清它们**（屏幕边缘变黑） | 改变玩法 + 代价 |

**为什么这是流派**：它把"停下来"从惩罚变成战术。现在的游戏里静止 = 等死。

### 流派 B · 掠夺者（RAIDER）—— 拿钱换命

> 幻想：「我知道会招来东西，但我要那箱钱。」

| 节点 | 效果 | 性质 |
|---|---|---|
| 贪婪（已有 GREED） | 金币 ×1.5，威胁 +2 | 已有 |
| 典当 | 花 200 金回 20 理智（有价治疗） | 新经济通道 |
| 赌徒 | 开箱 50% 双倍金币，50% 空 | 风险 |
| **王冠：金币即力量** | 每 1000 携带金币 +1% 移速与伤害（上限 +25%） | 把金币变成战力 |

**为什么这是流派**：它让"贪"变成一种可计算的赌注，而不是被动加成。

### 流派 C · 反击者（COUNTER）—— 被抓的那一刻反打

> 幻想：「你抓到我，就是你倒霉。」

| 节点 | 效果 | 性质 |
|---|---|---|
| 扳手专精 | 扳手造成硬直 + 推开更强（已有硬直曲线，这里加强） | 已有系统 |
| 挣脱 | 被抓时按键需求 -40% | 新 |
| 以牙还牙 | 受伤后 3 秒内移速 +30% | 新 |
| **王冠：反杀** | 被抓住的瞬间按空格可反杀一次（每局 1 次） | 改变玩法 |

**为什么这是流派**：它把"被抓住 = 结束"变成"被抓住 = 机会"，和 A/B 完全不同。

## 五、和现有 30 个节点的关系

不建议推翻重来 —— 现有 25 个倍率节点是"数值底座"，保留。改两件事：

1. **把重叠的分支合并**：SILENCE 与 CONCEAL 合成 GHOST；ECONOMY 与 RISK 合成 RAIDER；
   SHAPE 拆开分给 COUNTER 和 GHOST。
2. **王冠恢复排他**：同时只能持有一个王冠（换 = 花核心，已有的 `SkillSwitchKeystone` 直接改判定）。
   **这一条是流派感的开关** —— 不排他，加多少节点都会收敛。

## 六、排期的建议

| 阶段 | 内容 | 工作量 |
|---|---|---|
| 第 1 步 | **王冠排他**（一行判定）+ 支整合并（表结构调整） | 1 轮，低风险，立竿见影 |
| 第 2 步 | 3 个王冠（无形 / 金币即力量 / 反杀） | 2~3 轮，各需独立测试 |
| 第 3 步 | 6 个普通节点 | 2 轮 |
| 第 4 步 | 平衡回归（每流派一局，验证都能通关） | 1 轮 |

**为什么先做排他**：它不需要新内容，就能让现有的 8 个 keystone 重新变成"选一个"，
流派感立刻回来一半。这是投入产出比最高的一步。

---

## 附：一句话总结

现在的树是 **30 个节点、5 个名字、1 种玩法**。
把它变成 **3 个流派** 需要的不只是加节点，而是恢复**排他** ——
让"选了这个就选不了那个"重新成立。

### 6.2 逐条判定

#### ① 呼吸同步（静止后不掉理智）—— ❌ **不合理，是神节点**

- 静止 60 秒 = 省下 **30 点理智 = 上限的 30%**，等于白送 3 个安全屋。
- 更糟：怪物都追不上走路的玩家（见平衡报告），**站在角落就是绝对安全**。
  这一条会让"理智"这个全局计时器失效。
- **修正**：流失**减半**、且**最多持续 20 秒**（之后照常掉）。
  价值约 20 秒 × 0.25 = 5 点理智/次，可控。

#### ② 金币即力量（+1% / 1000 金）—— ❌ **数值算错了**

- 一局收入 2,433 金；就算全额带入，5,000 金 → **+5%**，等于没有。
- 而 5,000 金已经到 **T6（听觉 +30%）**，风险远大于收益。
- **根因**：我用了"金币"这个线性量，但这游戏真正的尺度是**强度档**（对数式阈值）。
- **修正**：**每个强度档 +1.5% 伤害与移速，上限 +20%**（T13 封顶）。
  T7（5,800 金）= +10.5%，和它带来的 +35% 听觉形成真实取舍。

#### ③ 王冠切换"花 3 核心"—— ❌ **不存在的货币**

- `cores` 在 v3.4 已**废弃**，全工程只有存档读写，没有任何产出。
- 而且满树只要 4 个核心（等价 4,000 金），"3 核心"= 满树的 75%，纯属乱写。
- **修正**：切换费**按金币结算**。建议 **2,000 金/次**（≈ 单局收入的 82%，
  足够肉痛但不至于锁死）。要更狠就 3,000（1.2 局）。

#### ④ 典当（200 金 → 20 理智）—— ⚠️ **方向对，数字要按层缩放**

- 20 理智 = **40 秒**基础存活时间；200 金 = 单局收入的 8%。
- 但中后期理智上限不变（100），理智流失却被难度/词条放大 → 
  固定 20 点会越来越不值钱。
- **修正**：**200 金 × 当前层数 → 回 20 点**（第 5 层 = 1,000 金）。
  和"价格随层数涨"的既有设计（`GoldSearchAt` 等）一致。

#### ⑤ 挣脱（按键需求 −40%）—— ✅ **合理**

- 蛛网窗口 5 秒、每次按键减 0.5 秒、下限 1 秒 → 现在要按 8 次。
- −40% 后 5 次，仍在 5 秒窗口内，属于"手更稳"而不是"无敌"。

#### ⑥ 以牙还牙（受伤后 3 秒 +30% 移速）—— ✅ **合理**

- 3 秒加速 = 多跑 9 格，刚好够脱离一次追击（`SCAV_CATCH_R 1.45`）。
- 代价是"先挨一下"，和流派主题自洽。

#### ⑦ 反杀（被抓瞬间按空格）—— ⚠️ **技术上要先收窄**

- 游戏里有 **4 种"被抓"**：清道夫抓人、宝箱怪咬、缚丝蛛网住、跳脸虫 QTE。
  每一套状态机不同，一次性全接是 4 个改动点。
- **修正**：第一版只接**清道夫抓人**（它是最常见的"憋屈死法"），
  其余三种留到后续。工作量从 ★★★★ 降到 ★★。

#### ⑧ 无形（静止 3 秒隐形）—— ⚠️ **可行但要砍掉"边缘变黑"**

- 隐形本身可以接在 `HasLOS` 上游（给怪一个"看不见"的判定），实现不难。
- 但"屏幕边缘变黑"和现有的烟雾暗化（`smokeDim`）、理智晕影（`vignetteOn`）
  **共用同一条管线**，叠在一起会打架。
- **修正**：第一版只做"隐形 + 移速 -25%"（代价用数值表达，不用视觉）。

### 6.4 王冠排他的正确做法（修正）

原提案说"切换花 3 核心" —— 核心已废弃，改成：

```
切换王冠 = 2,000 金（一次性，从银行扣）
购买第二个王冠 = 需要先把现有的卖掉，返还 50%
```

这样"选一个"有成本但不至于锁死（2,000 金 ≈ 0.8 局）。
