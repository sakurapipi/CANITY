# A. 表现层（本次重点细化）

## A1　局内整体页面：阴沉的蓝色 + 闪烁

**基调**：主题背景是**蓝色**，整体氛围**阴沉**。

**要做的三件事**：

1. **闪烁**
   - 局内整体页面带**偶尔的、不规律的闪烁**（像老旧灯管/供电不稳）；
   - 频率要低、幅度要小，**是氛围不是干扰**——不能影响玩家看清路；
   - 闪烁可以跟"理智档位"联动（越疯闪得越频繁）。

2. **暗角增强**
   - 进入局内后，**界面边框、提示、转场**三类元素都要做**暗角增强**：
     - 局内画面：四周压暗，中心保留可读区；
     - HUD 边框：边缘加深、内发光；
     - 转场（进出房间/状态切换）：用暗角收放做过渡，而不是硬切。

3. **胶片颗粒（砂粒感）**
   - 整个画面调整为**复古胶片相机**的质感：**颗粒感 + 轻微噪点**；
   - 颗粒强度**随理智下降而增强**；
   - **必须有上限**：设一个最大值，不能无限叠加到看不清（`grainMax`）。

## A2　字体：血腥感 + 精神污染

- 字体带一点**血色/血腥感**（描边、渗色、轻微笔画侵蚀）；
- 风格偏**精神污染**（压抑、不安、非理性），但**保持可读**；
- 关键数值（理智、危险提示）保留最高可读性，装饰只作用于标题与氛围文本。

## A3　理智只影响"观感"，分四档

**原则：理智不影响任何数值，只影响画面与音乐。**
理智越高越清楚，理智越低越疯。

| 理智区间 | 画面 | 音乐 | 视角 |
|---|---|---|---|
| **> 80%** | **完全清晰，无任何改变**（颗粒=0、无闪烁、无边角畸变） | **平缓** | **稳定** |
| **80% ~ 50%** | 出现轻微颗粒 + 偶发闪烁 | **节奏改变，带紧迫感** | 稳定（可极小呼吸感） |
| **50% ~ 20%** | 颗粒明显、暗角加重、色调偏移 | **明显更阴沉、更惊悚** | **开始崩坏**（轻微抖动/呼吸/边缘扭曲） |
| **< 20%** | 颗粒接近上限、闪烁频繁、精神污染字体启用 | **节奏变得疯癫、临近崩溃** | **明显崩坏**（持续抖动、视野扭曲、偶发抽帧） |

要求：
- 四档之间**过渡要平滑**（插值，不要一跨阈值就跳变）；
- 档位阈值集中定义在一处，便于调参；
- 验收：四档各截一张图，能一眼看出递进关系。

## A4　音乐扩展（素材由用户提供）

- 主题音乐会扩充，**由用户自行合成并导入文件**；
- 实现方需要：
  - 预留清晰的**素材接入位置**（文件名/目录/格式约定要写进文档）；
  - 支持按情境切换（菜单 / 局内 / 追逐 / 安全屋 / 低理智）；
  - 与 A3 的四档联动（同一情境在不同理智档用不同曲目或不同处理）。

- 【待设计】曲目与情境/理智档的映射表。

## A5　金币配色修正

所有"金币/黄金"的数值改为**金色系**（暖金），不要沿用主题蓝。
范围：主菜单、局内 HUD、商店、银行/结算界面。

## A6　主题房间重做

现有 7 种房间主题表现雷同，重做使其在材质、色温、陈设、光照上**一眼可区分**。

- 【待设计】7 种主题各自的视觉语言；用户会后续给出主题编排，实现方需先设计出可扩展的结构。

# C. 玩法

## C1　校准小游戏重做为**音游**（工作量最大）

**形态**
- **空格开始**；
- **QWER 四条校准线**；
- 屏幕**左侧一个小方框**，框内为音游区；
- 音符**从上往下掉落**（类似《钢琴块 2》），落到判定线时按对应键判定。

**音乐与谱面**
- 用游戏**当前主题曲**，**截取中间一个片段**（不用全曲）；
- 对片段做**节奏采集**，生成谱面（离线分析 → 谱面随包发布）。

**难度**
- **层数越高难度越大**（密度 / 下落速度 / 判定窗口）。

**失误与惩罚**
- 累计**弹错 5 次** → 立即判负、结束本次小游戏（不结算奖励）；
- 判负后 **30 秒内不得再进**。

**奖励（连击）**

| 连击 | 奖励 |
|---|---|
| 2 连 | +2 理智 |
| 3 连及以上 | +3 理智 |
| 单次上限 | **+10 理智** |

- 连续按**两下空格**退出。

**接入方式**
- 通过**调用现有校准入口函数**接入（具体函数由实现方在代码中确认并复用，不另起并行逻辑）。

- 【待设计】判定窗口、断连规则、音符生成算法、谱面数据格式。

## C2　取消「投石」技能 → 替换为新技能

- 现状：投石技能**没有动画**，占着热键 **G**；
- 要求：
  1. **取消投石技能**；
  2. 替换为**新技能**：`【待设计】由实现方设计`（潜行/逃生/资源/信息类，避免再做"无动画投掷"）；
  3. **释放热键 G** 给新技能；
  4. 新技能**必须有明确视觉反馈**。

- 交付物：技能名（中英）、效果、数值、技能树位置、G 键行为、视觉方案。

## C3　修整服务：按百分比付费 + CD

**付费规则**
价格与**当前理智**挂钩，**理智越低越贵**。用户示例（**仅说明方向，不是最终数值**）：

```
理智 30 → 60 金币
理智 50 → 30 金币
```

- 价格必须由**曲线/公式**推导，不许写死；
- **必须有价格预览**（按下去之前能看到要花多少）；
- 曲线与系数由实现方设计（要"修得起但不划算"）。

**CD**
- 同一修整服务加冷却，CD 内拒绝并提示剩余秒数。

- 【待设计】曲线、CD 时长。

## C4　补给商店加**刷新键**

- 新增刷新键（避开现有按键）；
- **刷新冷却 60 秒**；
- CD 内按下给出明确提示（剩余秒数）。

## C5　技能树扩展 + 结构重画

**结构**
- 现有 3 条分支：**北 / 西南 / 东南**；
- **画出一条主干线**串起三条分支；
- 分支节点 = **流派技能**；
- 主干线旁有**三片空白区域**，放**通用技能**与**弱关联技能**；
- 三片区域**颜色区分**、各有特点。

**扩展**
- 技能树**向外扩展**（容量变大）。

- 【待设计】总节点数、三片区域内容与配色、扩展后排布与美术方案。

**可读性（附带修复）**
- 节点短名目前只有 1 个字（界面上全是「静/轻/夜」），改成 **2~3 字**或提供悬浮全名。

# D. 怪物系统

## D1　三只听声鬼的数值与分工

| 序号 | 听力 | 特殊能力 | 速度 |
|---|---|---|---|
| 第 1 只 | **100%** | 无 | 基准 |
| 第 2 只 | **75%** | **减速技能** | 基准 |
| 第 3 只 | **50%** | 无 | **最快** |

**已知障碍**：当前 `BASE 1.90` / 上限 `2.10` / 倍率 `1.30` → 被夹到 2.10，相对基准最多快 10.5%，"最快"不成立。
实现方需重设速度与上限，使第 3 只**明显更快**，同时**不破坏"玩家永远跑得掉"**。

## D2　入场时间写成函数

新增函数（如 `HunterSpawnDelay(level)`）控制三只入场节奏：**层数越高出场越快**。不许散落魔法数字。

## D3　第一层强度削弱
第 1 层当前过难，需削弱（强度 / 数量 / 出现率）。

## D4　怪物出场规则重设计

- 削减各怪**出场频率**；
- 设定每种怪的**最低出场层数**（第 1 层不该出现的怪要排除）；
- 输出「怪物 × 层数」出现表作为实现依据。

## D5　追光鬼：**没有听觉，只被光吸引**

- 追光鬼**不靠声音**；
- **看到光源**（手电、信号弹、发光道具）就冲过去 —— 这才是它吓人的地方；
- 关灯的代价与收益因此成立（关灯避开它，但看不见路）。

## D6　追光鬼**双只互卡** Bug
场上有两只时互相卡住，其中一只完全不动。修复占位死锁（分离力/避让/目标抢占/状态机）。

## D7　蜘蛛怪加入图鉴

- 游戏内应有蜘蛛怪，代码是后期添加 —— **先确认是否存在**；
- **图鉴第 3 条「旧版记录」替换为蜘蛛怪**；
- 附带修正：图鉴标题「现行 2 / 6」与实际 7 条不符，计数改为按真实数量动态计算。

## D8　偷钱怪 / 宝箱怪出场率过低
提高权重，使其在合理层数能稳定遇到（与 D4 一起设计）。
