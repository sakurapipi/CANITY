CANITY v%VER%  (Windows x64)

■ 怎么玩
  1. 双击 canity.exe
  2. 主菜单：方向键选择，回车确认。移动 WASD，F11 全屏
  3. 大厅里按 TAB 可以在「基础升级 / 技能树」两页之间切换

■ 如果第一次双击弹出「Windows 已保护你的电脑」
  这是 Windows 对**所有**从网上下载的 exe 都会做的事，不是游戏有问题。
  两个办法，任选其一：
    A. 双击本目录下的「解除锁定.bat」，它会把文件的下载标记去掉，
       之后双击 canity.exe 就不会再弹。
    B. 右键 canity.exe → 属性 → 在「常规」页底部勾选「解除锁定」→ 确定
  如果弹的是蓝底那页（SmartScreen）：
       点「更多信息」→「仍要运行」。

■ 存档在哪
  优先存 canity.exe 同目录的 canity.sav；写不进去会自动退到
  %APPDATA%\Canity\canity.sav。
  如果屏幕顶部出现红色「SAVE FAILED」横条，说明几个位置都被拦住了
  （常见于安全软件的文档保护），把 canity.exe 加进杀软信任区即可。

■ 卸载
  直接删掉整个文件夹；存档若在 %APPDATA%\Canity，一起删掉。
