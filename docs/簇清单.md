## 后续适合独立处理的簇

1. 菜单/平台窗口事件：仍在 game.c，共享命中、拖拽、焦点和键边沿；不能只按函数长度搬走。
2. 开局/死亡/通关/银行结算：仍由 game.c 调度，应先确定运行记录与元进度归属。存档语义单独处理。
3. 更新阶段内的长按搜索、投掷和关卡转换：已经变成私有阶段，下一轮可在用户验证当前顺序后继续迁移。不要把阶段的“停止本步”误改成“只退出内部循环”。
4. render/entity/UI 的遗留块内 extern：先补所属契约头，再删重复声明。
