# CANITY 2.4.2 正式版

Windows、网页与手机触控版共用本次标签源码。保留 36×36 地图、12 个容器槽和原有玩法；本次重点修复 RC4 审计中的状态、经济、存档和输入问题。

## 下载与运行

- `CANITY_v2.4.2_win64.zip`：完整解压后直接双击 `canity.exe`，不需要 BAT 或 DAT。MP3 内嵌，首次启动释放到用户缓存目录。
- `CANITY_v2.4.2_web.zip`：解压后通过 HTTP 服务访问，支持桌面鼠标及手机触控。
- `CANITY_v2.4.2_web_single.html`：内嵌程序与音乐的单文件网页。部分手机不支持本地文件加载，请改用 HTTP 版。
- `build-manifest.json`：发布提交、编译器、附件长度和 SHA256。源码可从同一标签下载。
- 在线游玩：https://sakurapipi.github.io/CANITY/

默认桌面存档：`%LOCALAPPDATA%/CANITY/saves`；指定 `CANITY_DATA_DIR` 时使用指定位置。音乐缓存：`%LOCALAPPDATA%/CANITY/audio-2.4.2`。安装包不替换玩家存档，升级前请自行备份。

## 修复内容

### 训练、每日与经济

- 锁盘或校准界面中，B 键不能越过模态进入引导层。
- 所有新局在训练模式提前返回前重置局内升级、改造、威胁及单局反击消耗。训练中没有被动理智/电量消耗，训练携带金不能通过死亡或撤离结算流入真实银行。
- 保留训练营补给与毕业一次性 1500 启动资金的原设计；没有删掉训练奖励。
- 继续游戏恢复每日任务的观测基线，防止旧进度重复统计；重置校准瞬态，避免过期音游状态干扰续局。
- 节奏小游戏每层金币奖励严格封顶 90，封顶后仍可恢复理智和电量，六次失误才会被踢出。
- 局内强化成功立即保存。拒绝满载时的新钱袋投放，不吞掉旧钱袋或扣除新费用。
- 极端银行数值的取款计算先饱和再转换，避免整数溢出。

### 存档与档位

- 追加式升级至 v45，保存地上钱袋、拾荒者未追回赃款与单局反击已使用状态。旧 v44 之前布局保持不变。
- 继续后，未追回赃款变成原位置的可回收钱袋，原位置无效才回退到玩家位置；不会直接充值到钱包，也不会刷新同局偷钱次数。
- 修复 v25–v31 重排后错误使用旧长度判断字段存在性；恢复 v31/v32 读取。实际历史 v31 为 36×36、8 容器，v32 扩至 12，迁移分别处理。
- 保存到实际成功路径前才备份，包括设置保存；损坏主档不会覆盖有效 `.bak`。同一已选择档位在有效主档/备份中择新读取，不跨档位偷换进度。
- 切换档位为明确的保存旧设置、读取新档事务；不能在游玩中切换并覆盖另一个档位。无法读取的已有档位拒绝切换。
- 恢复时夹取电量、保险丝、搜索数、遗物等值；保留真实零电量、零携带比例等有效选择。

### 手机、网页与音频

- 输入清理同步重置触控私有状态；软切换地图后仍按住的摇杆可继续移动，切后台等硬清理则释放全部动作。
- 多指结束按手指身份分别处理，不再误停另一只手；新增挣脱/闪避按钮。
- 扳手短按执行轻击、长按蓄力、松开挥击，遵守同样次数和冷却；显示蓄力进度。
- 垂直触控转向接通真实俯仰渲染。暂停恢复释放残留输入并复位鼠标首帧。
- 手机保留存档工具，导入/导出绑定实际档位，也可明确选择槽位。
- 带触控屏的鼠标电脑不再一律当作手机；实际使用触摸时才切换触控层。
- 页面隐藏立即暂停并挂起音频，返回不会偷偷恢复游戏。
- 音乐切换淡入淡出，解码串行化，手机降低音频采样内存开销。保留全部音乐与合成回退。
- 每帧批量读取键盘、低理智模糊使用缩小暂存，减少跨边界调用与整帧拷贝。

## 审计中不采纳的推测

以用户原设计为准：不删除小游戏恢复、不恢复修整次数限制、不改小地图尺寸或容器数，不重新加入怪物出场字幕。强化接口成功值实际为 0，原有成功提示有效，只补上保存。舱门费用已经在目标与门槛验证后扣除，未重写为另一套退款流程。放弃旧局已有覆盖确认，未擅自赠送未结算金币；1 金死亡返还取整不改为强制补贴。

## 验证与兼容边界

发布工作流必须完成完整桌面构建、全部 15 个隔离运行域及内容检查，网页普通与单文件构建后从同一份产物发布 Release 与 Pages。失败返回码不被忽略，不跳过旧域。

新增旧版本夹具为按历史头文件生成的布局契约，明确不是历史玩家存档；它们不能替代全部玩家旧档验收。浏览器专项包含 33 项桌面、手机多指、混合输入、生命周期与全屏检查；手机为 Edge 模拟，不冒充实体 Android/iPhone 测试。实际发布日志与附件哈希见 Actions 和 `build-manifest.json`。

v45 是新格式，不能保证旧程序反向读取。请保留原存档及备份；不要把测试存档覆盖到自己的进度。
