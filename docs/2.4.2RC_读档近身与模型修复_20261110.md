# CANITY 2.4.2 RC — 读档、近身行为与模型修复

本轮只修改代码并生成运行包。没有运行游戏、测试、CI 或验收，也没有提交或推送。请由用户使用本轮代码重新验收，历史通过记录不代表本轮结果。

## 修改内容

1. 更新 tests/test_canity.c 的七类过时契约：教程敲击依据真实扳手动作记录；投掷提示检查实际绑定键；训练场临时能力入口按当前技能判断；每日冲刺及脱离追捕登记检查当前模块；低理智效果检查现有预生成遮罩与动态后处理；存档版本使用头文件常量并保留 v37/v43 迁移入口检查。
2. 纠正审计解释：投掷教程与 SK_DECOY 在当前代码仍存在，本轮没有按“已删除”误删其保护。
3. 读档后的地图以存档为准，旧主题装饰重建不再覆盖保存的墙体；无装饰缓存时清理旧地图元数据。剔除落在墙内或越界的装饰，再检查藏身点是否能从玩家所在区域到达。仅修复失效的位置，保留槽位编号及正常位置；没有安全替代位置时关闭该失效藏身点。
4. 读档后被藏身点绑定的玩家坐标同步修正，清除旧交互悬停与按住计时。普通玩家坐标按玩家碰撞半径判断，避免因柜体尺寸误把正常近墙玩家传走。
5. 第一只听声鬼不再因增援计时而处于“可见但不更新”的状态。增援生成计时不变。追击路径终点后，在近距离可见范围继续逼近玩家实际坐标；接触仍检查视线、隐藏状态、攻击冷却及硬直，不隔墙攻击。
6. 扳手的限时硬直属于原有反击机制，保留；防御处理无效/负数硬直和冷却，避免非法状态卡住。
7. 箱子统一闭合、锁定及已开三种造型，加入金属加强件、把手、铆钉、锁和内腔。电闸加入熔断器、通断电拉杆与指示灯；撤离门使用新的门框、面板与锁杆，并接入实际世界绘制入口，保留通电光柱。上述关键模型采用高分辨率烘焙，材质细节固定，避免每帧随机闪烁。
8. 保持版本 2.4.2 RC、存档 v44、36×36 地图、12 容器槽、64 世界精灵容量。新精灵编号仅末尾追加。
