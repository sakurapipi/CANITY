# CANITY v2.4.7 正式版

本版整理视角模式与中文本地化，保持 v45 存档结构、36×36 地图、12 个容器槽及 2.4.6 存档安全修复。

## 视角与设置

- 默认使用原版水平视角。墙体、地板、精灵、FOV 和后处理保留 v2.4.6 的独立实现，实验改动不再覆盖原版路径。
- 显示设置中的“上下视角(实验)”可手动开启约 ±6° 的垂直视野平移；保留试用后调整的纵向灵敏度。它是传统射线投射近似，不是完整三维俯仰。
- 每次载入游戏/存档默认关闭实验功能，不自动沿用旧试用包的 ON。切换时归零俯仰，并应用所选模式的镜头参数。
- 实验模式统一世界投影，消除旋转深度分母接近零的路径；保留低头地板平滑采样，取消几何摇摆和自动缩放。原版保持原有低理智表现。
- 贴墙也可以上下观察，未增加额外玩家碰撞距离或更改怪物碰撞规则。
- 数值基准维持眼高 0.5、墙高 1.0、水平中心 renderH/2；统一奇数渲染高度下道具与墙面的半像素中心差。
- 新增“恢复画面默认”：自动分辨率、窗口模式、不限帧、100% 画质、默认 FOV、Gamma 1.0、实验视角关闭。不会重置进度、键位、语言、音量或难度。

## 中文本地化

- 统一词条表扩充至 952 条，补齐设置、技能、图鉴、战役、每日挑战等文本。
- 修正词条优先级与设置标签先拼接后无法翻译的问题，同步内联中文回退文案。
- 重新生成 12/24/36/48px 字库，共 1044 字形，补齐“云、画、验”等缺字；保留 Noto Sans SC / OFL 许可证。
- 统一怪物与服务称谓，修正技能树实际按键和音乐小游戏失误次数、资源恢复说明。

汉化回归作为第 16 个独立运行域强制执行，保留全部用例；既有架构预算未上调。

## 验证范围

发布前运行桌面完整验证、16 个运行域、云同步与删除故障回归、维护工具、字形与词条清单、结构和耦合检查，构建普通/单文件 Web 并执行 Edge 桌面/触控浏览器专项。本地首轮 146 个编译/验证阶段零失败；加入独立汉化运行域后的 30 个增量验证阶段零失败，16 个运行域全部通过。Edge 浏览器专项 33/33 通过，普通/单文件 Web 构建、原生隔离启动、汉化清单及耦合闸门通过。发布流程对标签提交再次完整编译与验证；最终数字与源码 SHA 见发布验证摘要和 build-manifest.json。
