## 1. 移除 K 键开小游戏 ✅

**现状**：`loop_desktop_input.c:1242`
```c
if(currentState==STATE_PLAYING && vk=='K' && !repeat){CalibStart();return 0;}
```
在任意位置按一下 K 就启动音游，容易误触。

**改动**：删除该分支，换成说明性注释。
**保留的入口**：
- 藏身点内按空格（`CalibLock`）
- 安全屋 → 休整服务第 5 项（`shop.c:604 CalibStartAtStation`）

**验证**：游戏中按 K 无反应；藏身点/安全屋仍能开。

## 2. 藏身点最小间距 ✅

**现状**：已有 7 格主约束 / 5 格兜底（`loop_level.c:900-901`），但用户实测仍会两个刷得很近、别处一个都没有。

**改动**：
```
HIDESPOT_MIN_GAP2       49 → 100   （7 格 → 10 格）
HIDESPOT_MIN_GAP2_RELAX 25 →  49   （5 格 → 7 格）
新增：同一象限最多 2 个（两轮生成都加），让藏身点铺开而不是挤在出生点附近
```
证据：`src/loop_level.c`（两处 `bad` 判定后各加一段象限统计）。

**验证**：连续开几层看小地图上的藏身点分布；理论上不会再出现"两个挨着、远处没有"。

---

## 3. 校准判定区增大 ✅

**现状**：`HitWindow() = max(0.085, 0.18 - (层数-1)×0.006)` —— 第 1 层 180ms，每层减 6ms，最低 85ms。

**改动**：
```c
HitWindow() = max(0.16, 0.26 - (层数-1)×0.002)
CalibZoneScale() = HitWindow() / 0.26
```
第 1 层 **260ms**（+44%），每层只减 2ms，最低 **160ms**（原来 85ms，几乎翻倍）。

**验证**：藏身点开小游戏，前几个音符明显更宽容；深层也不再"手抖必失"。

---

## 4. 去掉"越打越快" ✅

**现状**：`CalibSpeedScale() = min(1.6, 1 + (层数-1)×0.025)` —— 深层音符下落速度最高 1.6 倍。

**改动**：恒为 `1.0`，并加 `FIXED_RESULT:` 标注（否则 stub_scan 会把常量返回判为未标注桩）。
**保留**：谱面密度仍随层数变化（`Enabled()` 在 4/8 层解锁更多车道音符），只是不再加速下落。

**验证**：深层进小游戏，音符下落速度应与第 1 层一致。

---

## 5. 小游戏失败不再踢出藏身点 ✅

**现状**：`Finish(3)` 里
```c
if(result==3 && hiddenIn>=0){hiddenIn=-1;resetInputState=1;holdTimer=0;keyPressed[...]=0;}
```
失误超限 → 直接把玩家从柜子里弹出来（还改了输入状态）。**这是 bug。**

**改动**：整行删除，只结束音游；提示文案从
「失误超限：已离开藏身点」→「失误超限：小游戏结束」。

**验证**：藏身点里故意打错 6 次 → 小游戏结束，**人仍在柜子里**，可再按空格重开（有 30 秒冷却）。

## 7. 小游戏窗口 UI 重叠清单与重排 ✅

**改前的问题（逐条）**：
| # | 问题 | 原因 |
|---|---|---|
| 1 | 「已恢复 +N 理智」压在按键行 QWER 上 | 恢复行在 `y+h-16`，按键行在 `target+12 = y+h-33`，间距仅 17px |
| 2 | 「连按两次空格退出」画在面板**外**（`y+h+8`） | 会压住世界/HUD 文本 |
| 3 | 轨道顶端与标题行只差 21px | `y+30` 起轨道，标题在 `y+9`，小字号下几乎贴住 |
| 4 | 判定线 `target` 与底部文字挤在一起 | 只有 45px 空间塞按键行+恢复行 |

**重排方案**（`ui.c RenderFrameCalibration`）：
```
标题两行：COMBO（y+8）          第 2 行：RESTORED（y+8+字高）
轨道：    从第二行下方 +10px 开始（laneTop）
判定线：  target = y+h-52（小窗口有兜底，不会高于轨道区 40px）
按键行：  target+12（判定线下方，保留原位但空间够了）
退出提示：移进面板内部 y+h-14（不再外溢）
音符下落比例：按 (target-laneTop) 计算，轨道变短也正确
```

**验证**：把窗口缩到 1280×720 再玩一次小游戏，检查四行内容互不重叠、退出提示在框内。
