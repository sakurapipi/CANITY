## 四、✅ 没做完的：283 处函数体内 extern

`docs/extern收编清单.md` 有完整分布。

**关键发现**：extern 最多的 5 个文件（game.c 65 / ui.c 45 / render.c 27 /
entity.c 24 / scavenger.c 16），**缺的头都是"无"** ——

它们引用的符号**从来没有在任何头文件里声明过**，只在各自文件里定义为全局。

所以这不是"删重复声明"，而是"**先给符号定归属、补进头、再删 extern**"。
每个符号都要人判断属于 loop / player / world / present 哪一层。

按每轮约 15 行的速度，283 处需要 **20~25 轮**。

## 五、没有做的：真正"拆散" game.c

**一行逻辑都没搬。** `game.c` 还是 9,557 行，`render.c` 4,180 行。

这 20 轮做的是「**谁认识谁**」的重构：

```
之前：所有人认识所有人（39 个文件都看得到 160 个全局）
之后：每个文件只认识自己需要的那一小撮（4 个契约头之一）
```

**但文件大小没变。** 要真正变小，需要把函数搬到新文件 —— 那是下一批 10~15 轮的活。
