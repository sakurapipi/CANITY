# CANITY v2.4.9

四色威胁进化与战术反制正式版。

- 威胁银行提供冷蓝、蓝紫、琥珀黄和血红四档。七类怪物随威胁变化，图鉴可按档位预览。新增七种反制工具与四个快捷槽，局外技能侧重机制，局内技能强化数值。
- 新手教程用菱形路标引导，训练场提供锁具、靶场、藏身与撤离演练。按 B 可直接进入训练场。生存指南可查看当前键位和反制方式。
- 重做投石、烟雾和胶水表现，保留回声弹扫描，移除连投回响。局内技能单击查看、双击购买。成就页支持中文并按完成状态排序。

相对 RC3，首次最终层每日通关奖金独立记录并随存档持久化，每个存档档位每天最多领取一次。旧日对局继续沿用开局规则。投石每次飞行对同一个怪物只结算一次，训练靶不会主动追击。战术道具撞墙会在合法位置结算，解丝溶剂遵守墙体遮挡。

原有 v45 存档可继续读取。本版使用额外的存档块记录每日通关奖金日期，原有存档主体布局不变。

Windows 包解压后运行 `canity.exe`，保留同目录的 `music/`。网页支持 ZIP 或单文件 HTML。附件与对应提交及 SHA-256 一起记录在 `build-manifest.json`。
