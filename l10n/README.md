# 中文本地化与字形

## 字形

- 中文不再用 GDI + 微软雅黑现画，而是烘成 **12/24/36/48px 单色点阵**，和 8×12 英文点阵共用同一行高、同一种整数缩放。
- 字形来源：**Noto Sans SC**（思源黑体），SIL Open Font License 1.1，允许商业使用、嵌入和再分发。
- 仓库里**不包含 TTF**，运行时也不依赖系统字体；只有 `src/cjk_glyphs.c` 里的子集点阵（源码实际用到的字）。
- 点阵图集属于 OFL 的衍生作品，发布游戏时必须保留 `l10n/OFL-NotoSansSC.txt`。

## 改翻译的流程

1. 编辑 `l10n/zh.tsv`（列：英文 / 中文 / 来源）。这是运行时唯一权威词条源。
2. 生成 C 表：

   ```bash
   python l10n/apply_tsv.py
   ```

3. 如果新增了汉字，重新烘图集：

   ```bash
   python l10n/bake_cjk_atlas.py
   ```

   脚本从 `src/**/*.c`、`src/**/*.inc`、`include/**/*.h` 的字符串字面量里收集字符；
   只改翻译不改汉字时可以跳过。

4. 检查覆盖与图集是否过期：

   ```bash
   python l10n/audit_l10n.py
   ```

5. 重新编译。`src/lang_table.inc` 和 `src/cjk_glyphs.c` 都是生成文件，不要手改。

## 运行时规则

- `Tr("en","zh")` 仍然可用，但中文模式下会**优先查 `zh.tsv` 生成的表**，表里没有才用第二个参数。
  这样不会出现“表里改了、调用点没改”的漂移。
- `Transl()` 保留动态前缀规则（如 `GOLD 500` → `金币 500`）。
- 词条里同一英文出现多个译法时，`export_tsv.py` 只保留第一条并打印冲突；需要人工取舍。
